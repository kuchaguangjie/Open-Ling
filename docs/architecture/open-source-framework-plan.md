# Ling 开源框架实施方案

日期：2026-08-07
状态：实施中

## 决策

- 软件代码采用 Apache-2.0 License，版权主体为上海啸群教育科技有限公司。
- 程灵、周舟、林乐水当前生产使用的最新版提示词随开源基础版发布。
- 提示词候选稿、来源蒸馏、研究过程、内部评审和评测数据不进入公开仓库。
- Ling、群心心理工作室、官方 Logo、应用图标、三位官方咨询师名称和官方形象不随 Apache-2.0 License 授权。
- 第一版咨询师扩展仅支持声明式数据包，不加载第三方可执行代码。

## 目标结构

```text
Ling Desktop
  → Counselor Package Registry
      → manifest / locale / prompt / assets
  → Counseling Core
      → prompt snapshot / context / memory / safety
  → Provider Adapter
  → Storage Adapter
```

咨询师包描述角色的身份、本地化文案、理论取向、正式提示词和资源索引。Memory 与安全基线由 Ling 统一管理，扩展不能声明额外权限或降低官方客户端的最低安全基线。

## 咨询师包 v1 边界

v1 支持：

- 稳定包 ID、版本和引擎兼容范围；
- 中英文名称、简介、擅长和开闭场文案；
- 理论取向和专业介绍；
- 咨询师核心提示词与实时会谈场景提示词；
- 头像、立绘、咨询室和开闭场资源的逻辑索引；
- 安全基线版本和额外策略声明；
- manifest schema 校验和兼容性检查。
- 同 ID 更高版本的受控更新；旧会谈继续使用已冻结的 Prompt snapshot。

v1 不支持：

- 插件内可执行 JavaScript/TypeScript；
- 插件直接访问 SQLite、Electron IPC 或本地文件系统；
- 插件自行发起网络请求；
- 插件覆盖平台安全策略；
- 审核制合作咨询师目录、签名分发和第三方专业认证（不属于第一阶段，也不建设自由上架的 Agent 市场）。

## 兼容策略

- 现有 `counselorId` 继续作为三个内置包的稳定 ID，避免老会谈失效。
- 新建会谈在 prompt snapshot 中增加咨询师包版本与内容哈希；老 snapshot 按原有版本读取。
- 历史会谈的显示不依赖当前已安装的包；必要的名称和提示词使用会谈级快照。
- 未知咨询师包不默认回退为程灵；加载时应返回可诊断错误，只在历史兼容层使用中性占位。

## 公开边界清单

公共版本保留：

- `packages/core/src/prompts/counselor-cores/{chengling,zhouzhou,linleshui}.md`；
- 三位咨询师的当前实时会谈任务提示词；
- 共同咨询价值观、基础安全策略和框架必需的任务提示词；
- 当前 App 正常运行所需的代码与配置；
- 不包含真实用户数据的基础回归测试。

公共版本排除：

- `docs/prompts/current-prompt-review.md`；
- `docs/qa/records/`；
- 内部候选稿、来源蒸馏、人工评审记录和非公开评测结果；
- 真实会谈、真实用户反馈、内部标注数据和 held-out 评测集。

`docs/qa/` 中的研究和评测报告已从公共准备分支移除。后续只有被明确改写为公共安全规范或合成测试的内容才可重新进入公共版本。

## 实施顺序

1. 建立许可、商标、第三方通知和公开边界。
2. 定义咨询师包 schema、校验器和内置 registry。
3. 将三位咨询师的描述、文案和提示词转为内置咨询师包。
4. 让 Core、会后整理和 Renderer 通过 registry 读取咨询师。
5. 在不改变现有素材打包行为的前提下，把视觉资源映射收口到包级逻辑索引。
6. 增加专业咨询师开发规范、标准目录脚手架、导入/更新 UI 和兼容性测试。
7. 完成公开历史和素材复核后，再准备对外发布。

## 发布禁止项

在所有发布门禁完成前，不得：

- 将当前私有 Git 历史直接转为公开；
- 将仓库中的所有图片、音频、字体和模型默认宣称为 Apache-2.0；
- 将评测通过宣传为“临床有效”、“危机干预安全”或对第三方咨询师的专业认证；
- 未经权利与隐私复核就推送公共仓库或发布安装包。
