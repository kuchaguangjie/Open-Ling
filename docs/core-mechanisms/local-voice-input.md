# 本地语音输入

更新日期：2026-07-30

Ling 的语音输入采用“安装包内置本地模型、可选第三方云端语音识别服务”的方案。用户不配置第二套 API 也能直接使用。

## 用户体验

- 咨询室输入框左侧提供麦克风按钮，发送按钮使用向上箭头图标。
- 本地模型已包含在 Ling 安装包中；App 启动后会在后台预先校验并准备，首次点击通常无需等待，并明确说明语音不上传。
- 若用户选择云端语音识别服务，首次点击会先说明上传、计费和确认后发送的边界。
- 听写期间，输入框下方显示麦克风状态和随音量变化的波形，识别文字实时写入原输入框。
- 用户可以随时停止、编辑已识别文字后再发送；语音输入不会自动发送消息。
- 麦克风权限被拒绝、设备缺失、模型准备或识别失败时，错误会留在输入区内并允许重试。

## 模型与运行方式

- 识别运行时：`sherpa-onnx-node`。
- 默认模型：X-ASR 480 ms streaming Zipformer Transducer，中文、英文及标点一体化 INT8 版本。
- 模型来源：`k2-fsa/sherpa-onnx` 官方模型发布，模型项目采用 Apache-2.0 许可证。
- Encoder 拆分后与其他模型文件直接随安装包分发；启动后在后台合并并校验各文件 SHA-256，校验通过后才原子替换现有模型目录。直接模型文件方案避免了 bzip2 解压造成的十几秒等待。
- 解压后的模型保存在 Electron `userData/voice-models`，不进入备份数据。

## 云端语音识别服务

- 火山引擎：Seed-ASR 2.0 小时版，资源 ID `volc.seedasr.sauc.duration`；兼容大模型 ASR 1.0 小时版和并发版。
- 腾讯云：实时语音识别 V2 WebSocket 接口，使用 AppID、SecretID、SecretKey 和 `engine_model_type` 配置。
- 阿里云百炼：实时语音识别 WebSocket 接口，支持 `fun-asr-realtime` 和 `qwen3-asr-flash-realtime`，使用 DashScope API Key、地域和 Workspace ID 配置。
- 非敏感配置保存在本地设置；Access Token、SecretID、SecretKey 和 DashScope API Key 单独保存在本地 secrets 表，不写入普通设置 JSON。

## 隐私边界

渲染进程通过系统麦克风获得单声道 PCM 浮点采样。本地模式把音频发送给主进程的独立识别 Worker，音频只在内存中流转，不写入文件、不上传。云端模式把实时音频发送到用户选择的第三方语音识别服务，并受对应服务商的计费和数据规则约束。两种模式都不会自动发送消息，只有用户确认发送的文字按普通消息流程保存。

## 工程边界

- 主进程负责模型状态、安装包资源校验、解压、Worker 生命周期和云端服务 WebSocket。
- Worker 独占原生识别器，避免推理阻塞 Electron 主线程。
- preload 只暴露受控的模型管理、识别开始/音频/停止和事件订阅接口。
- 渲染进程负责麦克风采集、带节奏缓冲的实时草稿合并和界面状态，不直接加载模型或原生模块。
- macOS 包声明麦克风用途说明；原生 sherpa 库通过 `asarUnpack` 随应用分发。
