# 项目简报

## 产品定位

Ling 是一个本地运行、用户自带大模型 API 的开源 AI 心理咨询桌面端。它通过固定咨询师、连续会谈、本地资料和会谈后整理，帮助用户进行情绪支持、自我探索与心理学学习。

Ling 由 GitHub 账号 `@Ling-Team` 维护，官方发行和版权主体为上海啸群教育科技有限公司。群心心理工作室是 App 内的 AI 咨询师团队设定，不是独立法律主体或真人心理咨询机构。

Ling 面向希望保留长期会谈脉络、又不希望产品默认把资料上传到自有云端的用户。它不替代专业心理咨询、精神科诊疗、医学诊断或危机干预。

## 当前体验

1. **进入工作室**：启动 Loading、首次使用说明、模型连接、本地密码锁和恢复短语。
2. **等待室探索**：三位咨询师轮值前台、底栏快速预约与来信、咨询师介绍、首次知情说明、故事簿、资料桌、沙发会谈记录和系统设置。
3. **连续会谈**：程灵、周舟、林乐水三位 AI 咨询师；流式回复、停止、重试、历史读回、会谈管理和结束/继续流程。
4. **本地资料**：SQLite 保存设置、个人资料、会谈、消息、`txt/md` 附件、摘要、概念化、督导、咨询备忘录和来信。
5. **上下文控制**：按 token 预算选择近期原文，必要时注入 rolling summary；每个会谈冻结咨询师提示词与上一周期已完成的咨询备忘录。
6. **会谈后整理**：结束后在后台完成会谈整理与咨询师来信；用户可以在整理期间开始新的会谈。
7. **用户控制**：个人资料、咨询连续性和后台模型分工可配置；支持 Markdown 导出、完整本地备份/恢复、阅读显示与本地密码保护。

## 数据与模型边界

- 设置、会谈、总结、记忆和来信默认保存在本机。
- 模型请求会发送完成当前功能所需的提示词、用户消息和受预算控制的上下文到用户配置的模型服务。
- 完整 API Key 只由 Electron 主进程读取，并通过系统安全存储加密保存在独立凭据文件中；它不进入 SQLite、备份或 Renderer。
- Ling 不提供自有云同步、遥测或默认外部上传。

## 当前版本不做

- 正式安装包、签名、公证和应用内自动下载安装；当前只检查官网版本号、提示新版本并打开官网下载页；
- PDF、DOC/DOCX、图片 OCR 与超大资料 chunk 检索；
- 完整资料管理中心、云同步和多人协作；
- 通用任务 Agent、插件系统、电脑控制或文件系统代操作；
- 专业诊疗、风险评估结论或危机干预服务。

## 当前成功标准

- 用户能启动 App、连接自己的模型服务并完成一次真实流式会谈；
- 三位咨询师的预约、会谈和历史互不串线，重启后可继续读取；
- 长会谈不会无界发送全部历史，跨会谈只承接同一咨询师已完成且冻结的后台整理；
- 用户可以查看归档和来信、导出可阅读资料、创建与恢复本地备份；
- 所有界面文案清楚说明 AI、本地保存、模型调用和非专业替代边界。
