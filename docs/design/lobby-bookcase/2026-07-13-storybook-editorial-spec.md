# 故事簿编辑排版与咨询师专栏说明

## 选定方向

- 保留现有故事角的左右双栏、文章列表和完整阅读页结构。
- 采用用户选定的第一种编辑排版：纸面目录、细分隔线、方形图片，不再使用绿色圆角主题块和白色圆角故事卡。
- 左栏从内容主题改为三位咨询师的故事专栏；头像直接复用聊天气泡头像，不另造人物形象。
- 右栏每位咨询师固定展示三篇，标准桌面高度下三篇可同时看见；卡片保持约 170px 高，图片与文字形成连续杂志目录。
- 视觉参考：`2026-07-13-selected-editorial-reference.png` 与 `2026-07-13-counselor-sidebar-color-ink-reference.webp`。

## 目录与阅读页终审版式

- 以用户确认的双状态参考图为主要排版标准，但不复刻参考图临时生成的 Logo；继续使用项目现有头像、工作室署名、木框与纸纹。
- 右侧三篇不再使用无间距的大幅彩色拼接。每篇改为纸面内横向缩略图 + 文字摘要，四周留白一致，以细分隔线串成一份连续目录。
- 列表缩略图统一降低饱和度、对比度与视觉亮度；仅在悬停或键盘聚焦时轻微恢复，使不同故事插图属于同一册而不互相争抢。
- 咨询师切换保留头像和左侧砖红选中线；键盘焦点也使用左侧线与浅色纸面反馈，不出现完整红色矩形框。
- 阅读页取消主图上方的独立工具条。页面顺序固定为“主图 → 返回故事簿 / 阅读时长 → 栏目标识、标题、导语与正文”。
- 返回操作与阅读时长置于主图下方同一轻量信息行，右上角关闭按钮只属于外层面板，不再与阅读操作争抢或重叠。
- 标准桌面高度下仍须同时看见三篇故事和底部续写提示，且不因十余像素的多余内边距出现无意义滚动条；移动端沿用同一信息顺序并缩小主图留白。

## 主线统一面板适配（2026-07-13）

- 同步 `main@6f488d1` 后，故事簿沿用大厅三面板统一的近满屏胡桃木底座、暖纸内页、双细线内框和外层关闭按钮，不再维护专题私有的框体尺寸。
- 1600 × 900 下，目录页使用约 30% / 70% 的双栏；右侧三篇各约 170px 高，图片与文字留白一致，列表不产生额外滚动。
- 1024 × 720 等低窗高环境下，三篇各收至 138px；元信息、主题、单行摘要和阅读操作同步缩小，优先保证三篇与续写提示完整同屏，而不是简单裁掉第三篇。
- 阅读页主图、图下操作行与正文纸张继续使用独立纵向滚动；任何窗口尺寸下，图下返回与时长都不进入右上角关闭按钮的点击区域。
- 阅读页文末在虚构与专业边界说明之后复用故事簿左栏的正式工作室 Logo，并以右对齐 `STUDIO FICTION COLLECTION` 落款收尾。

## 阅读展开页校准（2026-07-14）

- 进入文章后继续使用主界面的统一近满屏木框，不通过突然缩小弹窗来解决留白；双页改为约 44% / 56%，让封面页承担更多画面，正文页保持约 720px 的舒适长文行宽。
- 右页必须重复文章栏目标识、标题与导语，正文从完整文章头部开始；左页仍保留封面式标题，形成“封面页 / 正文页”的双重层级。
- 双页阅读区域整体缩进到内页细线以内；中缝只在阅读区域高度内出现，不与上下圆角边线相交。右页滚动内容也在同一缩进区域内裁切，任何滚动位置都不得越过上、下内框。
- 目录页定位文案应同时说明心理视角、故事均为虚构且并非咨询个案，并保留文学余味；三位咨询师的头像与选择行适当放大，使左页信息量与右侧目录平衡。

## 内容身份

故事不是咨询师个人经历，也不是对真实个案的转述。左栏姓名表示三位咨询师各自的虚构写作专栏与稳定文风，不使用“某某讲述”“咨询案例改编”等容易被理解为公开来访者材料的说法。

固定边界文案：

> 人物、情节与对话均为虚构；故事不对应任何真实来访者，也不读取你的会谈内容。
