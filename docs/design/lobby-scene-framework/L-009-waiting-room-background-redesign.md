# L-009 等待室背景定稿说明

状态：用户已选定，等待实现
日期：2026-07-12
执行工具：Codex
分支：`feat/waiting-room-background-redesign`

## 1. 目标

在不改变等待室核心空间关系的前提下，使用用户选定的新背景替换当前运行时背景。新版本保留原有前台 `Ling` 字样，并在前台后墙加入“群心心理”三人舟 Logo；同时改善墙面布局、咨询师像素肖像、三人合照、植物与装饰画的辨识度和差异性。

## 2. 最终母版

用户选定的本地生成图不随仓库分发。正式归档后使用语义化版本名，不直接引用生成工具的缓存路径。

## 3. 已确认视觉

- 画布维持 `1672 × 941`，与当前等待室坐标系及响应式舞台比例一致。
- 左侧窗户、湖景、窗帘、沙发、茶几、地毯、前台、书架、右墙肖像、留言板与资料柜的核心位置保持不变。
- 前台正面的绿色手写 `Ling` 字样保留。
- 前台后墙使用暗酒红金属质感的三人舟 Logo；图形无圆环、无文字、无波浪，严格保持三人和舟形。
- 后墙使用较矮、疏朗的小青竹，最高叶片低于 Logo 上沿。
- 后墙保留一幅叶子植物画和一幅小风景画；右上墙使用另一幅风景画；留言板叶子卡片改为风景明信片，避免重复。
- 右墙三位咨询师使用清晰像素风肖像，从左到右为周舟、程灵、林乐水。
- 程灵服装使用米白针织层次，参考正式主立绘，不使用白衬衫。
- 前台台面三人合照使用同一套像素人物识别。
- 左下花材、茶几花材和右侧矮柜植物互不重复；茶几花束温暖但低饱和，不成为主视觉焦点。

## 4. 图形与素材管理

- 三人舟透明母版位于 `assets/runtime/lobby/waiting-room/redesign/logo/`。
- 新背景正式图放入 `assets/runtime/lobby/waiting-room/redesign/`，保留生成来源和用户选定状态说明。
- 当前 `waiting-room-baseline-v1.png` 不删除、不覆盖，继续作为仓库内回退素材。
- 按用户要求，旧背景另复制到下载目录归档；归档副本不得成为运行时依赖。
- App 只引用新的正式背景文件，不引用候选图、QA 图或 Codex 缓存路径。

## 5. 响应式与热点

- 新旧背景画布尺寸和宽高比完全相同。
- 新图中的核心热点对象没有实质位移，因此预期沿用现有场景坐标，不修改共享热点总表。
- 实现后必须在 16:9、16:10 和窄高窗口检查：窗景、前台、书架、咨询师肖像、资料柜、沙发与茶几的热点仍落在对应物件上。
- 如发现偏差，在本文记录具体对象和建议坐标，再由大厅场景实现统一调整；背景素材分支不直接修改 `interaction/LobbyHotspotLayer.tsx`。

## 6. 允许修改

- `docs/design/lobby-scene-framework/` 中 L-009 设计说明。
- `assets/runtime/lobby/waiting-room/redesign/` 中本任务素材与说明。

- 与当前实现重复的过程记录。

## 7. 禁止修改

- `waiting-room-baseline-v1.png` 原文件。
- 任心人物素材与位置。
- 热点最终坐标及 `interaction/LobbyHotspotLayer.tsx`。
- `LobbyPage.tsx`、共享状态、功能登记表、路由、IPC、会谈逻辑与其他专题素材。

## 8. 验收

- 新正式背景与用户选定母版可见内容一致；母版实际宽度为 1671 像素，正式文件仅复制最右侧 1 像素列补齐为 `1672 × 941`，不缩放画面。
- 运行时只切换背景引用，旧背景仍可回退。
- `npm run typecheck`、`npm test -- --run` 和 `npm run build` 通过。
- 16:9、16:10 和窄高窗口均无拉伸；核心物件可见，热点未出现可观察偏移。
- `prefers-reduced-motion` 下背景与热点可用性不受影响。
- 素材来源、选择状态、运行时文件、旧图归档位置和热点结论均有记录。

## 9. 可否证问题与降级条件

可否证问题：新背景能否在不增加咨询入口阻力、不破坏热点命中的情况下，提高等待室的品牌一致性、人物辨识度和空间细节质量？

停止或降级条件：

- 若新背景在常见窗口比例中导致核心入口被危险裁切，则先回退旧背景引用。
- 若热点与物件出现明显错位，本任务只记录偏差并回退或等待 `S-003`，不越界修改共享热点。
- 若正式文件与用户选定母版不一致，禁止接入运行时。
