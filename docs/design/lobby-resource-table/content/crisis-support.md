## 一、定位

这不是心理咨询教材，也不是让用户完成的风险问卷。它是一张放在 AI 心理咨询软件里的“心理危机行动页”：当强烈绝望、情绪失控、解离感或伤害念头让人难以维持安全时，让读者先稳定当下、把危机说出来、让念头与行动拉开距离，并连接现实中的陪伴和专业支持。

本稿从零撰写，没有参考或沿用资料桌原有的安全正文。当前网页用于共同审阅信息层级、短文案和交互；本轮依据 WHO、NCTSN / 美国国家 PTSD 中心的开放心理急救指南，以及 Johns Hopkins、Cengage 的专业危机干预教材介绍重新组织行动顺序。它仍不能替代针对中国本地法律、特定人群与具体危机场景的专业审阅。

## 二、网页结构与当前短文案

### 1. 首屏：直接说明内容主题

- 标题：`心理危机与安全支持`
- 紧急标题：`如果你担心自己或别人马上会受伤`
- 适用情况：`请立刻告诉身边可信赖的人你在哪里，并联系所在地的紧急服务。中国大陆可拨打 110 或 120；不要等待 Ling 或心理热线的回应。`
- 紧急号码：`110 公安报警`、`120 医疗急救`，以大号红色数字并排显示，但仅作信息展示，不是链接或拨号按钮。

首屏不增加“已核验资源”等状态标签，也不另起“联系现实支持”作为标题，避免读者误解页面主题。它不使用长篇解释，也不让用户先完成判断或继续阅读才显示紧急号码。`110`、`120` 是页面唯一使用克制红色的号码；其余心理援助与就医资源使用灰绿色，避免把热线与现场紧急救援混为一类。

### 2. 心理危机中的低负担行动

专业原则仍保留表达危机、稳定当下、限制危险和连接支持，但不再把这些专业步骤直接写成训练式标题。区块标题改为 `如果现在真的很难熬`，并明确：`不用按顺序，也不用全部做到。下面挑一件你现在还做得到的，就够了。` 页面允许读者做不到、暂时说不清，也不要求先理解术语。

| 面向读者的标题 | 一句补充 | 点击后展开的重点 |
| --- | --- | --- |
| 先让一个人知道，你现在很难受 | 不用讲完整，一句“我现在不太安全，能陪我一下吗”就可以 | 说不出话时把页面给对方看；告诉对方位置和安全情况；已经行动或服药过量时立即联系紧急服务 |
| 先只照顾眼前这一分钟 | 不要求立刻平静，也不用马上想明白 | 用看、听、触摸回到眼前；呼吸使恐慌加重时跳过；只做一件小事 |
| 把危险暂时放远一点 | 不是要求马上振作，只是给最难受的感觉一点过去的时间 | 离开危险地点和物品；暂停饮酒、驾车、争执和独处；把不可逆决定延后十分钟 |
| 找个人陪你，把这一小段熬过去 | 请对方到身边、保持通话或陪同求助 | 陪伴不等于说服；可直接询问自杀或伤人念头；安全计划留待与专业人员共同完成 |

卡片使用原生 `details / summary` 交互，键盘和点击均可展开；展开提示改为 `如果你愿意，可以再看一点`。关闭状态只显示一句有人味的行动，避免在高压力下先出现大段文字。页面不让用户自行打分，也不把短暂稳定技巧写成治疗或安全保证。

### 3. 已核验的现实资源

号码区放在情境行动之后，允许用户向下滚动到达。页面只保留中国常用资源，不再设置地区切换标签。紧急服务永远排在心理援助热线之前；热线不描述成现场救援服务。所有号码均为不可点击的纯信息展示，并明确写出 `Ling 不会发起拨打、外呼或派出救援`。

### 4. Ling 的能力局限

当前页以 `不要把 Ling 当作紧急服务` 为标题，并明确显示：

> Ling 不能确认你是否安全，也不能定位、报警、通知亲友或派出救援。遇到危险，请直接找现实中的人和服务。

发布前需再次按产品真实能力复核这段文字。任何未来的能力变化都不能在没有真实接线、人工值守和责任流程的情况下改成“Ling 会替你求助”。

## 三、编排与交互原则

- 目录卡片点击后进入独立行动页，并可返回资料目录；不改另外两份资料正文。
- 先显示一个占据视觉中心的紧急行动框，再显示大字情境行动；号码与能力局限放在下方，不要求用户读完才求助。
- 用短标题和一句话卡片，不放原因、症状清单、科普长文或自测问卷；不为压进首屏而缩小字号。
- 不使用“高危 / 中危 / 低危”，不暗示 Ling 已完成风险判断。
- 当前只展示中国常用号码，不提供地区选择，也不自动推断用户所在地；使用前应核对所在地适用的号码。
- 所有号码显示最近核验日期；服务时间不确定时明确写“以所在地实际安排为准”。
- 页面按已确认效果图使用暖象牙纸、胡桃木、暗森林绿、细金褐边线和低对比纸纹；各情境、电话、医院图标均为同一组生成线稿素材。
- 紧急提示依靠顺序、尺寸和清楚用词建立优先级；仅 `110`、`120` 的数字使用克制红色，不使用整块恐吓式红色警报。
- 号码不使用 `tel:` 链接，不打开电话应用；本任务未新增定位、报警、共享状态、外呼或 IPC 能力。

## 七、仍需专业文件回答的问题

1. “辨认—稳定—拉开距离—连接真人”的行动顺序，是否通过自杀预防、暴力风险和危机干预专业人员审阅？
2. “远离可能造成伤害的物品”“不要独处”“不要独自对质”分别在哪些情境可能增加危险，是否需要更精确限定？
3. 理解与求助能力不同的使用者、依赖照护者、性暴力受害者和施害者分别需要哪些独立入口、法律说明与强制报告边界？
4. 当对方拒绝帮助、要求保密、失联或身处异地时，陪伴者应采取什么有依据的现实行动？
5. 当前中国单列资源由谁负责号码、服务时间和失效状态的定期复核；未来是否需要增加地区选择？
6. 是否需要为无法说话、行动受限、设备受监控、需要额外照护支持和使用读屏工具的用户补充经地区核验的替代路径？
7. 当前“没有真人持续查看、不能定位、报警、通知亲友或派出救援”的产品事实，是否通过发布前技术与运营复核？
