# Ling 使用帮助

> 内容版本：2026.08.26<br>
> 当前 App 正文来源：`apps/desktop/src/renderer/pages/lobby/features/resources/userGuideContent.ts`

Ling 是一款采用 Apache-2.0 开源许可的 AI 心理咨询 App。群心心理工作室是 App 内的 AI 咨询师团队设定。首次使用前会先完成欢迎、隐私说明、解锁密码和模型连接引导，然后进入工作室等待室。App 内的程灵、周舟和林乐水是由人工智能大语言模型驱动的 AI 咨询角色，不是三位正在电脑另一端工作的真人咨询师。

这里的“AI 心理咨询”指 AI 提供的支持性对话与自我探索，不等同于由具备专业资质的真人提供的心理咨询。Ling 不能替代真人心理咨询、心理治疗、精神科诊疗、医学诊断或危机干预。

你不必准备好才来，也没有必须完成的流程。想从哪里说起、谈到什么程度、什么时候停下，都由你决定；你也可以检查、纠正或拒绝 AI 的理解。

<a id="meet-ling"></a>

## 认识 Ling 和咨询大厅

Ling 不只是给通用模型换了名字。它围绕心理咨询场景设计了咨询师设定、会谈方式、安全边界、上下文与记忆处理，以及会谈后的整理流程。

核心咨询系统的研发参考心理咨询伦理、相关理论与公开研究，并通过情境测试检查回应边界。相关设计和内部测试不构成执业资质、临床验证或效果保证。

打开 Ling 后，你会先来到群心心理工作室的等待室。第一次进入时，工作室助理任心会做简短接待。场景中的柔光圆点可以打开不同区域；底栏可以直接查看咨询师的信、预约咨询或打开系统设置。

项目说明与咨询师扩展规范将在公开仓库开放后提供。如果对产品、隐私、安全或知情同意有疑问，可以联系 openling@xiaoqunpsy.cn。

<a id="choose-counselor"></a>

## 认识和选择咨询师

点击等待室墙上的三张咨询师照片，可以打开介绍册。

- **程灵｜人本—心理动力取向**：关注感受、关系经验、内在需要与冲突，重视在被理解的过程中慢慢探索。
- **周舟｜焦点解决取向**：关注你期待发生的改变、已经有效的部分和可用资源，与你一起寻找具体、适度、可行的下一步。
- **林乐水｜中国传统心性哲学取向**：关注身心、现实处境与价值方向，也会借助中国传统心性哲学理解关系、责任、得失与人生变化。

三位角色背后仍是人工智能模型。不必寻找“最正确”的选择，先选择此刻更愿意与之交谈的人就可以了。

<a id="start-session"></a>

## 开始一场新咨询

选好咨询师后，点击“预约咨询”。如果模型尚未连接，Ling 会先引导你配置服务；第一次开始前，还会显示完整的 AI 心理咨询知情同意书。由你确认是否继续后，Ling 才会建立本地会谈。

进入前，咨询师会先做开场接待；你可以逐句阅读，也可以跳过。正式进入后，左侧是会谈列表，中间是对话区，右侧显示当前咨询师和回应状态。每场会谈会保留创建时选择的咨询师和模型。

若同一咨询师已有未结束的会谈，选择“开始新咨询”会先结束旧会谈并建立新会谈；已结束的历史会谈不会被改动。

<a id="during-session"></a>

## 表达、发送与重试

- 在下方输入框写下想说的话。
- 点击“发送”或按 Enter 发送。
- 使用 Shift + Enter 或 Alt/Option + Enter 换行。
- 咨询师回应时，页面会显示正在理解、整理或回应。
- 某条消息失败时，点击消息旁的“重试”。
- 可以把文件随消息保存；当前只有 TXT 和 Markdown 文本会被读入模型上下文，图片、PDF 和 Word 等格式只记录文件信息。

你可以不回答某个问题，也可以直接说“我不想谈这个”“换个方向”或“我想先停一下”。

<a id="voice-input"></a>

## 使用语音输入

在咨询室输入框左侧点击麦克风，可以把说话内容转成可编辑文字。识别结果只会写入输入框，不会自动发送；你可以先检查和修改，再决定是否发给咨询师。

- **本地识别**：默认使用安装包内置的离线中英文模型。第一次启用时需要确认并等待几秒完成准备，录音不会上传。
- **云端识别**：可在“设置 → 语音输入”选择火山引擎、腾讯云或阿里云百炼。开始使用前会再次提示音频发送与可能计费。
- **开始与停止**：点击麦克风开始听写，再点一次停止；按发送时，Ling 会先结束听写并保留最终识别文字。
- **快捷键**：可以设置仅在 Ling 窗口位于前台时生效的组合键，按一次开始，再按一次停止。

Ling 需要系统麦克风权限。请在发送前确认识别文字准确；如果不想保留，可以像普通草稿一样修改或删除。

<a id="pause-or-end"></a>

## 停止、离开与结束

| 你想做什么 | 使用哪个按钮 | 会发生什么 |
| --- | --- | --- |
| 不再等待当前回应 | **停止** | 只停止这一条回应，会谈仍可继续 |
| 暂时去大厅看看 | **返回等待室** | 离开咨询室，但不会结束会谈 |
| 完成这次咨询 | **结束本次咨询** | 确认后锁定输入，开始会谈整理和写信 |

结束后如果还想补充，点击“继续本次咨询”即可重新打开输入框。需要离开时，再点击“返回等待室”。

<a id="next-session-preparation"></a>

## 结束咨询之后

结束咨询后，Ling 会在后台整理这次咨询并准备咨询师来信。相关步骤由你配置的 AI 模型完成，没有真人咨询师或真人督导师在后台查看、值守或即时接管。你可能会看到：

- 会谈转为只读，并开始后台整理；
- AI 生成单次与长期整理、独立检查和咨询备忘录；
- 已完成的咨询备忘录可按设置承接到同一咨询师之后的新会谈；
- 来信写好后保存到等待室底栏的“咨询师的信”。

处理期间可以返回等待室，也可以开始其他咨询，不会因此中断后台整理。

如果此时选择“继续本次咨询”，Ling 不会采用此前尚未完成的整理和来信；再次结束后，会按补充后的完整会谈重新整理。

<a id="manage-sessions"></a>

## 继续和管理会谈

咨询室左侧会显示当前咨询师的进行中会谈和历史会谈；等待室沙发旁的“会谈记录”可以集中回看已经结束的对话。

- 点击会谈名称进行切换。
- 点击顶部“+”新建；同一位咨询师已有未结束的会谈时，可以选择继续旧会谈，或让旧会谈进入结束流程并开始新会谈。
- 历史会谈出现后，可以使用其上方的搜索框。
- 打开会谈旁的操作菜单可以重命名；符合删除条件时也可以删除。

第一次发送后，会谈名称可能自动变成一个简短主题。

<a id="past-understanding"></a>

## 让新会谈承接过去理解

结束会谈后，Ling 会生成仅供后台使用的咨询备忘录。同一位咨询师可以在下一场新会谈中使用已经完成并冻结的备忘录，帮助对话自然衔接。

这些材料不会作为可阅读的咨询总结展示，不会跨咨询师共享，也不是对你的定论，不会代替你当下的表达。你随时可以关闭它：

1. 打开“设置 → 咨询连续性”。
2. 找到“新会谈承接同一咨询师的后台整理”。
3. 按需要开启或关闭并保存。

这个选择只影响之后创建的新会谈，不会改写已有会谈。

<a id="session-letter"></a>

## 查看咨询师的信

正式结束一场咨询后，Ling 会调用你配置的模型服务生成咨询师来信。你可以留在会谈中查看写信状态，也可以先回到大厅。

回到等待室，点击底栏的“咨询师的信”，可以：

- 搜索来信或按咨询师筛选；
- 先看预览，再打开完整信件；
- 在写信失败时选择“重新生成”。

<a id="fees-and-usage"></a>

## 了解费用与用量

Ling 官方发行方不收取软件下载费、咨询费、订阅费或使用费。使用中可能产生的费用，只来自你接入的模型服务商。

- **Ling 本身**：官方发行方不收取软件下载费或使用费。
- **费用来自哪里**：生成回复、整理会谈材料和来信需要调用模型服务。接入 DeepSeek、Kimi、GLM、Qwen 等云端服务时，由对应服务商按其定价计费，额度、优惠、限速和账户规则也以该服务商为准。
- **本机模型**：接入本机模型时，内容不离开这台设备，也不会产生模型服务商的调用费用。
- **查看用量**：在“设置 → 用量与费用”中可以查看今天和最近 7 天的 Token 消耗，并按服务商和模型分组。
- **费用怎么算**：Ling 只记录 Token 数量，不计算也不显示金额。具体费用按模型服务商官方单价计算，最终以服务商账户账单为准。

模型服务商的价格可能调整。开始使用某个服务前，可以在它的官网查看当前定价、免费额度和计费规则。

<a id="data-and-models"></a>

## 了解资料与模型边界

Ling 默认把设置、个人资料、会谈、后台整理和来信保存在这台设备上，不提供自有云同步、遥测或默认外部上传。需要模型生成内容时，相关资料仍会发送到“模型接入”中配置的 Base URL。

- **模型请求**：可能包含系统提示、你的消息、个人资料片段、受预算控制的近期对话与摘要、可读附件，以及已经完成的后台整理材料。
- **服务商规则**：模型服务商怎样保存、使用和删除请求内容，以及是否按其定价计费，由对应服务商的规则决定。
- **本机保存**：会谈、消息、设置、个人资料、附件记录、后台整理和来信默认保存在本机；API Key 由主进程通过操作系统安全存储加密保存，不进入本地数据库或备份。
- **解锁密码**：会加密本地会谈、来信、记忆和设置；恢复码用于忘记密码、换设备和恢复加密备份。
- **语音输入**：内置本地识别离线运行，录音不上传；选择云端识别服务时，实时音频和鉴权信息会发送给对应服务商，并可能由你的服务商账号计费。
- **Markdown 导出**：供阅读，不包含 API Key、附件原文件和后台整理材料，文件本身没有加密。
- **完整本地备份**：采用加密格式，用于迁移与恢复，包含本地资料但不包含 API Key，恢复后需要重新配置模型服务。

请只连接你信任的模型服务，并把导出文件、备份和恢复码保存在只有你或你信任的人能够访问的位置。

<a id="settings"></a>

## 调整常用设置

大厅底栏的“系统设置”，可以打开当前常用设置：

- **模型接入**：配置 DeepSeek 或兼容 OpenAI 接口格式的服务，测试连接，并分别选择咨询对话与会谈后整理使用的模型。
- **用量与费用**：查看今天和最近 7 天的 Token 消耗；Ling 本身免费，费用以模型服务商定价为准。
- **语音输入**：使用安装包内置的本地中英文识别，或配置火山引擎、腾讯云、阿里云百炼；也可以设置仅在 Ling 前台生效的快捷键。
- **个人资料与语言**：填写希望咨询师使用的称呼和愿意提前提供的背景、更换头像，并在简体中文与 English 之间切换界面和专业内容语言。
- **咨询连续性**：决定新会谈是否承接同一位咨询师已经完成的咨询备忘录。
- **界面与阅读**：调整会谈与资料阅读区域的文字大小和行距。
- **数据与隐私**：设置本地解锁密码和免密窗口、导出会谈与来信、创建或恢复加密的完整本地备份，以及恢复推荐设置。

个人资料中的称呼和背景会用于之后的咨询对话；不想提供的内容可以留空。

<a id="troubleshooting"></a>

## 遇到问题

### 不能发送消息

确认已经进入一场未结束的会谈。如果咨询师正在另一场会谈中回应，需要先等待或停止那次回应。仍然无法发送时，到“设置 → 模型接入”重新测试连接。

### 返回大厅后找不到原来的会谈

点击大厅底栏的“预约咨询”，选择原来的咨询师。进入后，从会谈列表选择原来的会谈；已经结束的会谈也可以从沙发旁的“会谈记录”回看。

### 后台整理失败

在结束后的会谈中点击“重新整理这次咨询”。你也可以继续原会谈，补充完成后再次结束。

### 来信还没有出现

若页面仍显示咨询师正在写信，请稍后等待或到等待室底栏的“咨询师的信”刷新；若提示生成失败，可以选择“重新生成”。

### 附件没有被理解

确认附件是 TXT 或 Markdown。图片、PDF 和 Word 等格式当前只保存文件记录，不会进入模型上下文。

### 语音输入无法开始

先检查系统麦克风权限。若使用云端识别，再到“设置 → 语音输入”核对服务商凭据和已开通资源。

### 忘记本地密码

使用设置解锁密码时保存的恢复码重设密码。Ling 无法替你找回未保存的密码或恢复码。

### 恢复备份前

恢复会替换这台设备上现有的 Ling 本地资料，并重启 App；API Key 不在备份中。请先确认选中的文件和当前资料是否需要另行备份。

你可以停止当前回应、暂时返回等待室、结束咨询，或关闭 Ling；这些操作对会谈和未发送草稿的影响并不相同，详见“停止、离开与结束”。
