# L-013 资料桌设计规格

状态：资料桌已实现，完整知情同意已接入<br>
执行工具：Codex<br>
最近安全修订分支：`feat/crisis-support-safety`

## 设计目标

把等待室右下方的资料桌改造成清楚、安静、可信的工作室资料入口。用户点击后先看到三份资料，并能进入正文阅读；资料桌不承担长期阅读、身体调节、系统配置或真实数据记录。

可否证问题：用户是否能在进入页面后快速理解三项资料分别解决什么问题，并在不产生紧张或游戏化感受的情况下找到安全边界？

停止或降级条件：如果装饰素材削弱正文可读性、窄窗口下遮挡返回操作，或安全内容被视觉效果弱化，则减少装饰层并保留清楚的纸面目录与正文结构。

## 已确认内容

首版仅保留三个入口：

1. `使用帮助`：工作室用途、开始/继续/结束咨询、附件与本地保存的简短说明。
2. `危机与安全支持`：现实支持优先、即时危险下的行动指引、已核验资源与 Ling 的能力边界。
3. `知情同意`：直接打开资料桌完整版本；不在这里保存或改变首次确认状态。

首版不加入访客留言册、会谈前便笺、呼吸练习、音乐、身体觉察、长期文章或系统设置。

## 视觉基准

目录入口采用用户确认的三张二维手绘插画卡；正文阅读继续沿用既有暖纸与胡桃木工作室框架。

- 大面积暖象牙纸作为主阅读面；
- 胡桃木外框与克制的细金线建立资料桌的空间语义；
- 三张竖向插画卡横向排列，分别使用橄榄绿、陶土红和暖灰米色；
- 插画保持克制可爱、水粉蜡笔式二维质感，不使用写实书本或额外叶片装饰；
- 等待室背景在覆盖层后保持可辨认，但降低亮度和对比度；
- 不使用 RPG 背包、收集品、徽章、数值或拟物到影响可用性的装饰。

## 素材分层与管理

生产素材放入 `assets/runtime/lobby/resource-table/`，按用途保留：

- `frame/`：胡桃木外框与纸面底板；
- `cards/`：三张无字透明插画卡及其生成源、抠图与验收证据；
- `tabs/`、`icons/`：保留给正文旧版结构使用，不再承担目录入口主视觉；
- `ornaments/`：植物线稿和细金线角花；
- `source/`：必要的生成源图或抠图源；
- `qa/`：仅在制作阶段保存合成检查图，提交时只保留必要证据。

正式界面使用透明 PNG/WebP 分层组合。CSS 只负责布局、响应式、文字、焦点和状态，不用渐变或大量伪元素临摹木框、纸纹、页签、图标和植物装饰。

## 页面结构

### 资料目录

- 顶部：`资料桌`、`工作室使用资料`、关闭按钮；
- 主体：三张竖向插画卡；插画和底部浅色信息区由 PNG 提供，标题、用途说明和 `查看` 由 App 实时渲染；
- 卡片整体可点击，同时保留清楚的键盘焦点；
- 知情说明在真实接口尚未提供时仍可进入说明页，但显示“完整知情说明将在首次咨询流程完成后接入”，不得伪造确认状态。

### 内容阅读

- 保持同一纸面与木框，不打开第二层弹窗；
- 顶部提供 `返回资料目录`；
- 长正文使用舒适行宽和稳定标题层级；
- 安全内容直接、清楚、可执行，不使用诗意隐喻；
- 关闭后返回等待室原状态。

### 完整知情同意

- 以 `content/informed-consent.md` 作为唯一正文来源，界面在构建时读取并拆分用户正文，不展示内部编写与审阅记录；
- 进入后先看到导读、版本和八章目录，不把完整正文一次铺满；
- 桌面窗口使用左侧常驻目录 + 右侧单章阅读，底部提供上一页、下一页；
- 较窄窗口继续保留可滚动目录与独立正文区，并与使用帮助采用相同的响应式结构；
- 第 2 章将三位咨询师介绍显示为独立资料卡，第 6 章的现实求助步骤使用克制的重点样式；
- 本入口只负责完整阅读，首次短版、主动确认、版本记录和重新确认仍属于 `S-002`。

### 使用帮助与知情同意统一阅读骨架

- 两页共用顶部返回与标题区、左侧目录、右侧单模块阅读区和同一套窄窗口响应式规则；
- 使用帮助继续按五组主题展示对照卡、步骤和提示，知情同意继续按导读与八章正文展示；
- 统一仅发生在布局骨架，不合并或改写两份已完成内容；
- 危机与安全支持接入同一资料目录，但保持独立行动页和原布局，不纳入双栏阅读骨架。

## 状态

- 默认：显示三项资料目录；
- 阅读：显示所选资料正文；
- 空状态：内容数据为空时说明“这份资料暂时无法显示”，保留返回目录；
- 加载状态：正文区域显示克制的文字加载提示，不使用抢焦点动画；
- 失败状态：说明读取失败并提供重试与返回目录；
- 长文本：纸面内部滚动，标题、返回和关闭操作持续可达；
- `prefers-reduced-motion`：取消入场和卡片位移动效。

## 内容边界

`危机与安全支持`必须明确：

- Ling 提供情绪支持、自我探索、学习和研究辅助；
- Ling 不能替代专业心理咨询、精神科诊疗、医学诊断或危机干预；
- 若用户正处于即时自伤、伤人或其他紧急风险，应优先联系当地紧急服务和现实中可信赖的人；
- 用户可以随时暂停、退出或结束咨询。

2026-07-31 安全修订进一步要求：

- 中国大陆资源只展示职责稳定且已核验的 `110`、`120`、`12356`，不混列易过期的地方号码和单一城市医院示例；
- 把紧急救援与心理援助分层：`12356` 提供真人心理援助，但不替代 `110`、`120`、急诊或现场救援；
- 受伤、服药过量、中毒或身体异常时直接联系医疗急救，不以观察症状、文字陪伴或感官练习延迟处置；
- 危险物只写“拉开距离、让现实人员介入”的原则，不要求用户或陪伴者搬运、转交、争夺或自行处置；
- 陪伴者仅在自身安全时保持在场；暴力、武器或现场危险存在时先撤离危险范围并报警；
- Ling 不持续监测在线、掉线或现实安全，不把 AI 回复表述为专业风险评估结论。

不根据用户状态做风险判断，不提供地区号码猜测，不把安全提醒写成任心对白。

## 工程边界

资料桌主体只修改：

- `apps/desktop/src/renderer/pages/lobby/features/resources/`；
- `assets/runtime/lobby/resource-table/`；
- `docs/design/lobby-resource-table/`、专题测试和必要的大厅入口回归断言。

不修改 `LobbyPage.tsx`、功能登记表、热点总表、共享 store、IPC、知情说明持久化、花园、书架或设置。若打开接口需要跨模块调整，直接在对应实现与长期设计说明中记录并完成联调，不再创建 handoff。

## 验收

- 视觉与确认效果图在结构、材质、层级和空间气质上接近；
- 16:9、16:10 和常见窄高窗口中三项入口、返回与关闭可用；
- 键盘焦点、语义按钮与减少动画设置有效；
- 空、加载、失败、阅读和长文本状态有测试覆盖；
- 素材目录语义清楚，正式资产无脏边、色溢和多余背景；
- 专题测试、类型检查和构建通过。
