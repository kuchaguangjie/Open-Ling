# Ling Q版箭头光标设计记录

## 开源参考

- [Bibata Cursor](https://github.com/ful1e5/Bibata_Cursor)：参考其紧凑的 Material 箭头、SVG 源文件和 Windows 16/24/32/48px 分级。
- [Phinger Cursors](https://github.com/phisch/phinger-cursors)：参考其 24/32px 基础网格、独立热点元数据和按状态拆分的方法。
- [Apple Cursor](https://github.com/ful1e5/apple_cursor)：参考箭头、I-Beam 等系统语义在 Windows/Linux 多尺寸主题中的映射方式。

上述项目只用于理解光标结构和制作原则。Ling 的路径、配色、高光和状态标记均为项目内重新绘制，没有复制对方的 SVG 资产。

## Ling 方案

- A 奶油经典：暖奶油色、深棕轮廓、鼠尾草绿可点击标记。
- B 鼠尾草胖箭头：轮廓最饱满，鼠尾草绿主体和暖金状态标记。
- C 桃杏轻巧箭头：轮廓稍细，桃杏色主体和灰蓝状态标记。
- D 月光纯白：纯白主体、深灰轮廓和单色状态反馈，整体最克制。
- E 软糖圆尖：保留箭头指向性，把尖头和所有转角进一步圆润化。

每套均包含默认箭头、可点击小手、按下小手和文字输入四个 32×32 SVG。小手颜色跟随各方案主体色，按下态会略微下沉并出现反馈线；文字输入态使用深色上下端帽，中间竖线与箭头主体同色。箭头热点为 `(3, 3)`，小手热点为 `(12, 3)`，按下小手热点为 `(12, 4)`，I-Beam 热点为 `(16, 16)`。禁用和等待状态保留系统语义光标。
