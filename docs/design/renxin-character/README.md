# 任心角色视觉系统

状态：已确认并接入

## 角色定位

- 22 岁左右，刚大学毕业，在 Ling 工作室担任咨询师助理。
- 少年感、温和、耐心、机灵，外形清爽但不偶像化。
- 不承担心理解释、诊断或咨询建议；视觉上不能误认为咨询师。

## 已确认统一形象

- 画风：温暖的手绘动画电影感，简洁线条、平涂与轻水彩质感。
- 五官：少年型柔和脸颊、清澈深色眼睛、自然鼻口、深蓝黑短碎发。
- 服装：米白翻领衬衫、鼠尾草绿针织背心、深色直筒裤、挂绳胸牌；胸牌自然嵌入群心标志。
- 道具：对白立绘夹一本浅棕色记录本；前台小人双手自然交叠。
- 姿态：对白立绘略微侧向、身体比例自然；前台小人正面站在柜台后。

## 动画拆层

所有图层共用同一画布、人物尺度和锚点；身体、发型、服装、文件夹始终不动。

- `base`：无眼睛与嘴巴变化的固定身体底图。
- `eyes-open`：默认睁眼。
- `eyes-half`：眨眼过渡。
- `eyes-closed`：闭眼。
- `mouth-closed`：默认闭口。
- `mouth-small`：小开口。
- `mouth-medium`：中开口。

眨眼序列：睁眼 → 半闭 → 闭眼 → 半闭 → 睁眼。单次约 180–240ms，低频随机触发。

说话序列：闭口 → 小开 → 中开 → 小开；文字逐字出现期间低幅循环，结束后回到闭口。

前台小人只播放低频眨眼，不播放口型或身体动作；位置经过等待室实际背景校准，避免悬空、过高或遮挡前台标志。

## 验收

- 任意帧切换时，脸型、头部、头发、身体、衣服与文件夹不漂移。
- 眼睛与嘴巴以外的像素保持一致。
- 表情温和自然，不出现夸张游戏表演。
- 透明边缘在等待室背景、白色、黑色与暖灰背景上无脏边或紫色溢色。
- 降低动态偏好下可固定为默认睁眼和闭口。
