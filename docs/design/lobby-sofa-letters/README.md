# 沙发来信角设计说明

状态：已被新的入口分工取代；来信功能保留在底部导航
执行工具：Codex
分支：`feat/lobby-sofa-letters`

> 2026-07-15 更新：底部导航已经承担“咨询师的信”入口，沙发区改为“会谈记录”。新的设计方向见 [`../lobby-consultation-history/README.md`](../lobby-consultation-history/README.md)。本文保留为原来信档案的设计与实现依据，不再代表沙发热点的当前功能。

## 目标

把原设置页“咨询师的信”迁移为等待室沙发区的私人来信入口。沙发承担“会谈后坐下来，慢慢读信”的空间语义；书架继续只承载工作室公开故事，资料桌继续承载使用帮助与安全说明。

## 最终方向

视觉参考：`final-reference.png`

- 使用等待室背景上方的场景内覆盖层，不切换到独立全屏页面。
- 外框采用厚实但克制的圆角暖木框、内嵌米白纸面和细线角花。
- 保留原来信页的信封素材、咨询师头像筛选、搜索、状态、选中态和信纸排版。
- 主体改为两栏：左侧约 35% 为来信列表，右侧约 65% 为大幅信纸预览。
- 完整信件继续复用现有信封、火漆、纸纹、签名和日期阅读器。
- 不显示未读红点、来信数量提醒、奖励、收藏或催促文案。

## 交互

1. 用户悬停或聚焦沙发/茶几热点，看到“来信”提示。
2. 点击后打开来信档案；背景保留并轻微压暗。
3. 用户可以搜索、按咨询师筛选、选择信件、刷新或重新生成失败来信。
4. 点击“打开完整信件”进入现有完整信纸阅读器。
5. 关闭完整信件回到原选择；关闭档案回到等待室。

## 状态

- 加载：读取本地来信。
- 空：说明结束一次会谈后来信会在这里等待。
- 搜索无结果：保留筛选与清空搜索能力。
- `pending`：显示正在写信并自动轮询。
- `ready`：显示信纸预览和完整阅读入口。
- `failed`：显示错误和重新生成。
- 整体读取失败：提供重新读取。

## 响应式

- 宽屏使用两栏。
- `1024×720` 等紧凑窗口压缩列表宽度和间距，但保持两栏可读。
- 更窄窗口切为“列表 → 预览”的单栏流程。

## 可否证问题

沙发入口是否让私人来信比设置页更容易被理解为“会谈后的安静回看”，同时没有增加游戏化、提醒负担或隐私暴露？

停止或降级条件：如果沙发热点与窗景持续冲突、窄窗口无法保持可读，或完整阅读器在覆盖层内形成不可控的焦点/Escape 问题，则降级为明确的矩形热点和单层阅读流程。
