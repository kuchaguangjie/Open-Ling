# 三位咨询师左向会谈立绘：生产方案

更新时间：2026-07-13
执行工具：Codex
状态：历史制作方案，仅在后续重新制作左向人物状态图时参考。

## 目的与位置

素材用于咨询室最右侧的常驻人物层。人物在右、来访者与对话内容在左，因此三人应保持正面看向用户，同时以身体重心、椅子、骨盆和交叉腿向左侧微倾，呈现稳定的陪伴与关注，而不是把脸转向画面左边。

## 当前视觉基线

- 程灵：长棕发、绿松石首饰、米白披肩与深棕长裙、深木扶手椅、花纹茶杯。
- 周舟：短深棕波波发、浅蓝衬衫与米白内搭/长裤、浅木布椅、蓝线条陶杯。
- 林乐水：低马尾棕发、米白针织开衫与灰绿色长裤、浅木布椅、花朵陶杯。
- 当前产品的目标画布为 `1024 × 1536`，右栏显示宽度约 `540–600px`；候选不再沿用程灵旧版的 `986 × 1595` 尺寸。

## 生成契约

| 项目 | 约束 |
| --- | --- |
| 锁定元素 | 三人身份、发型和发色、衣着与首饰、椅子材质/颜色、杯子、柔和插画质感、全身坐姿 |
| 允许变量 | 躯干、椅子与骨盆左倾 5–15°、左向交叉腿、双手/杯子位置、克制的左手说明动作 |
| 禁止项 | 换脸、换发型、服装或杯椅换款、脸和眼神转向左侧、身体/交叉腿朝右、夸张说话手势、桌子/背景/投影、凌乱碎发、裁切椅脚 |
| 画布与锚点 | 统一 `1024 × 1536`；椅脚接触线 `y=1450±30`；双眼中心 `y=350±35`；杯子中心固定在各人腹部至胸下的安全区 |
| 源图与透明 | 暖白/浅灰马赛克、平光无投影；后续生成透明 PNG，候选先保留可抠的源图 |

## 三个动作组

1. **在场 `present-left`**：正脸看用户，椅子和交叉腿向左，身体重心微向左；杯子双手持或单手安放在腿上。
2. **倾听 `listening-left`**：正脸看用户的前提下，身体向左前倾约 5–8°；杯子落在一手或腿侧，另一手自然搭扶手/膝侧；表情更专注而非忧伤。
3. **回应 `responding-left`**：正脸看用户的前提下，骨盆与交叉腿左向；仅一只手向左做低位、掌心向上的解释手势；另一手稳住杯子或让杯子可靠地位于膝上；不可遮挡脸、不可越过人物左侧安全边界。

## 批次与筛选

- 初始共至少 90 张：每人 × 3 动作 × 10 候选；每组最终保留 6 张通过质量门槛的候选，不足则继续补跑。
- 每组 10 张不是十次微小随机扰动：候选按 4 种头颈角度、3 种躯干倾角、3 种手/杯子组合交错覆盖，确保可选择。
- 先按硬性门槛淘汰，再从每组保留 6 张合格图供选择；若某组不足 6 张合格图，再补跑该组，不能用缺陷图凑数。
- 生成与筛选阶段保留在不提交的候选工作目录；用户选定后才输出最终透明资产、接入映射与提交。

## 质量门槛

1. 身份、发型、衣服、杯子和椅子与现有主立绘一致。
2. 不允许手指、杯把、椅子透视、腿脚或披肩穗子结构错误。
3. 同屏叠放与快速切换时，眼睛、椅脚和杯子位置稳定；切换缩放差不超过约 3%。
4. 透明抠图在真实咨询室背景、黑底、白底和暖纸底都无毛边、漏底、色溢或被吃掉的细节。
5. 实际右栏尺寸仍能读出正面陪伴感、身体左向的空间关系和动作差异。

## 交付节奏

1. 批量生成并按上述质量门槛剔除明显失败、重复、非左向候选。
2. 输出九张联系表（每人三张、每张保留六候选）及真实右栏合成预览。
3. 用户从每人三个动作组中各选一张；如无明显胜出，再针对该组做一轮受控补跑。
4. 对入选九张做抠图、锚点统一和真实 UI 验收；得到授权后才替换生产映射。
