# 程灵主线三态新版画风源图与透明交付 v1

生成日期：2026-08-14；表情与透明版修订：2026-08-15（倾听透明版 v7）

生成方式：Codex 内置 ImageGen，多参考图受控生成

状态：三态 `1024 × 1536` RGBA 透明 PNG 已完成五背景验收，并已接入主线咨询舞台预览

## 生成目标

用用户批准的新参考图锁定程灵的脸部与新版画风，同时严格沿用当前主线咨询场景的三种动作：

- 默认态：双手在身体中线持杯；
- 倾听态：画面左手托腮，画面右手持杯；
- 表达态：画面左手掌心向上，画面右手持杯。

复杂书房背景不进入人物源图。默认与回应使用低对比规则马赛克源图；倾听 v4 为彻底重绘的纯洋红抛光底源图，旧倾听图不再用于正式抠图。

## 参考图职责

- 新脸部与画风参考：锁定柔和椭圆脸、琥珀棕杏仁眼、眉鼻口、克制微笑、成年女性的温柔灵动气质、深棕细线稿和柔和半厚涂新画风。
- 当前主线默认/倾听/表达立绘：分别锁定身体动作、头部角度、手臂关系、杯子位置、椅子透视、裙摆与鞋子锚点。
- 默认态新版源图：倾听与表达两态的身份及资产母图；两态只借用对应主线图的动作骨架。

## 三态统一资产

- 杯子：乳白色小型圆腹杯，细深棕金边，画面右侧小圆弧杯把；正面为红橙玫瑰徽章与青绿色叶片纹。
- 服装：暖象牙色 V 领内搭与同色几何编织纹长袖披肩/开衫，宽袖、前襟与长流苏；深棕高腰长裙保留统一暗纹、长垂褶和裙摆。
- 鞋：同一双深棕尖头细中跟鞋。
- 椅子：暖深胡桃木高背扶手椅，米色/浅杏色几何织纹靠背和坐垫。
- 首饰：两侧同款古金包边椭圆蓝绿色耳坠；胸骨中线的小型绿松石/翡翠吊坠。吊坠石体与金色包边约为旧尺寸的 75–80%，最大宽度不超过 V 领横向宽度的四分之一。
- 发型：深栗棕中分长卷发，保留新参考图的大波浪剪影；减少极细飞丝、树枝状分叉、半透明发丝和内部镂空，每侧主要由 2–3 组连续卷发块构成。
- 画布：源图与透明版均为 `1024 × 1536` PNG；透明交付为 8-bit RGBA。人物、椅子、双鞋、双手与杯子完整可见，保持头顶和底部安全边距。

## 表情修订 v2

- 倾听态 v2：技术检查曾通过，但用户确认其脸颊、眼型与成熟度偏离身份基准；保留文件作为反例，不进入正式候选。

- 表达 v2 已获用户认可，继续保持，不参与倾听态重生成。

## 倾听表情候选 v3（历史，已被 v4 取代）

- A 专注确认：眼神更集中，表情最克制；与倾听 v1 的杏仁眼、成熟偏长脸、下颌下巴、鼻口比例和头部透视保持最佳。预审 `95/100`，首选候选。
- B 温柔共情：虽然语义成立，但脸颊更圆、眼裂更短、下巴存在感下降，成熟度偏离；预审淘汰，不进入联系表。
- C 沉静思考：身份基本保持，闭嘴且更安静；头面比例与局部纹理重绘略多于 A。预审 `89/100`，备选候选。

## 透明化与边缘修复

- 默认与回应：并行比较 `bria-rmbg`、`birefnet-portrait`、`isnet-general-use`、`isnet-anime` 和 `u2net`；以 `birefnet-portrait` 作为主蒙版，用 `isnet-general-use` 的高置信局部蒙版修复深色扶手端点和浅色流苏。
- 倾听 v4：从纯洋红源图构建柔边 alpha，再以邻近的真实头发、木材和米白流苏材质回填边缘，去除洋红/紫色溢色；不改动脸、手和杯子。
- 倾听透明版 v6：根据实际咨询页截图重新比较五种分割模型；对头发外轮廓和流苏执行局部栗棕/米白材质回填，清除首次抠图遗留的大面积红紫色边缘。
- 倾听源图 v5：因洋红底持续污染发缘，停止继续修补 v4；以默认和回应态锁定身份与资产，只借用托腮姿势，在浅灰白规则马赛克底从头生成三张。A 的身份、手部受力与三态一致性最佳，成为正式源；B、C 仅保留为候选。
- 倾听透明版 v2：比较 `bria-rmbg`、`birefnet-portrait`、`isnet-general-use`、`isnet-anime`、`u2net`，选择 `bria-rmbg` 主蒙版，并对两组浅色流苏执行局部暖象牙色回填；不再含洋红源色。
- 倾听透明版 v4：根据咨询页放大截图，只处理左右头发外轮廓约 2–6 像素的低饱和白灰残留；保留原始明暗纹理并回填栗棕色，对最外层使用距离渐变轻微收紧 alpha。中间试验版 v3 因产生分段色块未接入。
- 倾听透明版 v7：按坐标分区复核头顶、左右发缘、内侧发缝、右肩发卷和两组披肩穗子；仅对右侧发卷三段浅灰白残留做局部材质补绘，并给穗子中性灰像素增加克制的暖象牙色，保持原 alpha、流苏长度、衣服纹样和椅子结构。越界产生色块的 v5 试验版未接入。
- 三张均在黑、白、棋盘格、暖米色和实际咨询室背景上检查了发梢、手指、杯把、浅色衣服、流苏、椅子及内部空隙。

## 验收结论

- 三张均为同一个程灵，脸型、五官、成熟度与新版画风一致；倾听态为已通过脸部与手部专项质检的全新重绘。
- 三种动作与当前主线语义一致。
- 杯子、衣服、裙子、鞋、椅子、耳坠和缩小后的胸口吊坠保持同一资产。
- 三张透明 PNG 尺寸、人物比例、底部锚点和发型剪影一致。
- 未发现明显多指、手杯融合、托腮悬空、开放掌错误、腿脚穿插、裙褶或椅腿透视硬伤。
- 透明边缘在黑白两极背景上无大块脏边、棋盘残留或扶手透洞；倾听发梢和流苏的洋红溢色已局部修复。
