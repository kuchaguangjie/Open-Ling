# 沙发来信、资料桌、书架统一视觉方案

状态：A 方案已确认并完成正式实现  
日期：2026-07-13  
执行工具：Codex  
分支：`feat/unified-lobby-panel-style`

## 1. 结论

推荐采用“同一间工作室的三种纸面工作区”方向：以资料桌当前的胡桃木实木外框、暖象牙纸面和灰绿色交互色为唯一视觉母版，把书架与沙发来信现有的 CSS 渐变木框替换掉；三块面板共享品牌头、外框、内纸、关闭按钮和基础视觉变量，只在内部信息结构与少量主题标识上区分。

统一后不追求三页像复制粘贴，而是让用户明确感到它们属于同一间“群心心理工作室”：

- 资料桌像工作室的资料夹；
- 书架像工作室整理的故事册；
- 沙发来信像工作室留给用户的私人信件档案。

## 2. 参考图分工

- 资料桌：材质与颜色母版。采用它的木质厚度、暖纸色、克制金线和灰绿色。
- 书架：品牌布局母版。保留 Logo + `群心心理工作室` 的组合意识，以及左栏与内容区的编辑式层级。
- 沙发来信：信息密度与私人阅读体验母版。保留搜索、咨询师筛选、来信列表和大信纸预览。

这次不把任一张现有截图整张照搬到另两页，而是抽取共同视觉骨架。

## 3. 统一视觉骨架

### 3.1 外层木质背板

- 统一复用资料桌的胡桃木材质方向，保留真实木纹、圆润倒角和适度厚度。
- 三块面板使用同一外框宽度与圆角比例；默认大窗口外框约占面板短边的 `2.4%–3%`。
- 去掉书架、来信当前偏平的棕色 CSS 渐变边框，避免三块面板一块像实木、一块像塑料描边。
- 木框亮度略低于资料桌现状约一个层级，让注意力回到内容，但不改成深红木或厚重古典相框。

### 3.2 内层纸面

- 三页统一为暖象牙主纸色，建议基础色域 `#F3E8CC` 至 `#FAF2DE`，正文内容卡使用更浅的 `#FFF9EA`。
- 纸纹统一为低对比细颗粒，不让斑点抢字；三页不再各自叠加不同强度的网点、渐变和泛黄。
- 内纸与木框之间保留一圈窄暗缝或内阴影，强化“纸板嵌在木框里”的质感。
- 页面内部的卡片、信纸、文章纸张都来自同一色阶，只用明度和一条细边界区分，不另起一套黄白色。

### 3.3 边纹处理

资料桌现有四角连续叶片纹样全部删除。推荐改成：

- 一道外侧浅金细线 + 一道内侧半透明棕金细线；
- 四角只做 `10–14px` 的圆弧转折，不放叶片、花瓣或对称角花；
- 允许在页面右下或左下出现一处 `4%–7%` 不透明度的植物线稿水印，但不同时在四角重复；
- 长文阅读页若内容靠近底部，水印自动隐藏，避免压字。

这样保留工作室温柔、自然的气质，又不会让资料桌比另外两页更“花”。

### 3.4 品牌头

三页都显示同一枚正式 Logo 和完整名称 `群心心理工作室`，统一为横向紧凑品牌头：

```text
[Logo]  群心心理工作室
        当前空间的小标题或说明
```

- 品牌头固定在左上安全区，与关闭按钮形成左右平衡。
- Logo 与名称属于同一个可复用组件，避免资料桌只有弱化 Logo、沙发没有品牌、书架单独使用大侧栏品牌。
- Logo 建议高 `42–54px`；名称使用中等字重，不能小到像版权标记，也不应压过页面主标题。
- 页面主标题仍各自保留：`咨询师的信`、`资料桌`、`故事角`。
- 窄窗口下品牌头只缩小，不隐藏完整名称。

### 3.5 统一控件与色彩

- 主文字：深胡桃棕 `#3F3126`。
- 次文字：暖灰褐 `#786B58`。
- 主交互：鼠尾草灰绿 `#667A60`。
- 选中底色：低饱和浅绿 `#DDE3CF`。
- 细线/分隔：半透明棕金 `rgba(151, 116, 70, 0.26)`。
- 关闭按钮统一为暖纸圆钮、细金棕边、同尺寸的 `×`，悬停只轻微加深和抬升。
- 返回、搜索、筛选、卡片 hover、焦点环使用同一套状态规则；不再让三页各自定义绿色和圆角。

## 4. 三个页面分别怎么落

### 4.1 沙发来信

- 外框换成资料桌同款木质背板，纸面色同步。
- 左上加入统一品牌头；原 `咨询师的信 / 坐下来，慢慢打开` 下移为页面标题区。
- 保留顶部搜索与刷新、咨询师筛选、左侧来信列表、右侧信纸预览，不改变数据和操作层级。
- 来信卡与预览信纸改用统一纸张色阶；信纸可保留更细腻的专属纹理与信封火漆，这是它的功能识别点。
- 移除外纸面角花；右侧信纸原有植物装饰降到极低对比，避免和统一边纹重复。

### 4.2 资料桌

- 继续作为视觉基准，但做减法，而不是完全不动。
- 现有左上弱化 Logo 改为清楚的 Logo + 完整名称横向品牌头。
- 页面标题 `资料桌` 保持居中，目录以三张竖向手绘插画卡建立清楚的入口层级。
- 目录页删除额外叶片装饰；正文阅读页继续沿用统一纸面与木框。
- 橄榄绿指南针、陶土红电话、暖灰知情文件三张插画卡作为资料桌专属语义；业务文字和交互状态由 HTML/CSS 承载。

### 4.3 书架故事角

- 外框换成资料桌同款实木背板，主纸面与资料桌完全同色阶。
- 左栏顶部使用统一横向品牌头，下面再放 `故事角`；保留主题分类与隐私说明。
- 右侧故事卡继续保留场景插图和编辑式列表，这是故事角的核心辨识。
- 卡片背景从当前偏白、偏独立的色块收回统一纸色；插图边缘和卡片圆角按统一规格收口。
- 内页阅读继续保留大图 + 文章正文，但标题、返回按钮、分隔线与页脚进入统一视觉变量。

## 5. 共享与独立的边界

### 应共享

- 木框与纸面壳；
- 双细线内框；
- Logo + 工作室名称品牌头；
- 关闭按钮；
- 色彩、纸纹、圆角、阴影、焦点和减少动态规则；
- 大中小三档响应式安全边距。

### 不应强行共享

- 沙发来信的列表、信封、火漆与信纸；
- 资料桌的文件页签和三枚资料图标；
- 书架的主题导航、故事插图和文章阅读排版；
- 各专题加载、空、失败文案和业务状态。

建议实现一个只负责视觉壳的共用组件，例如 `StudioPanelShell` 与 `StudioBrandHeader`；专题内容仍留在各自目录。共享代码只覆盖三块面板已经真实共用的部分，不提前抽象业务组件。

## 6. 版式比例建议

- 统一外框最大宽度：约 `1400px`，宽屏占视口 `94%–96%`。
- 统一外框最大高度：视口 `90%–92%`，保留等待室环境边缘。
- 品牌与页面标题安全区：左 `4.5%–5.5%`，上 `4%–5%`。
- 关闭按钮安全区：右、上各 `2.2%–2.8%`。
- 内容区与品牌头之间至少留 `24px`，避免 Logo 成为漂浮装饰。
- 1024×720 仍保留木框和品牌名；内部布局优先压缩留白，再考虑单栏切换。

## 7. 实施顺序

1. 先在三张同尺寸高保真静态稿中统一外框、内纸、品牌头和边纹。
2. 用户确认统一骨架后，建立共用视觉壳和变量，不先动业务结构。
3. 先改资料桌作为基准页，再依次套到书架、沙发来信。
4. 最后逐页修正内部卡片与阅读页的纸张色阶，并做三联截图对比。

## 8. 下一轮高保真稿的视觉合同

用途与位置：等待室内三块覆盖层的统一视觉审阅。  
当前视觉基准：资料桌胡桃木框与暖纸面。  
锁定元素：三页信息结构、功能入口、Logo 图形、完整工作室名称、现有信封/资料图标/故事插图。  
本轮允许变化：木框亮度、品牌头尺寸与位置、双线边框粗细、单处植物水印位置。  
禁止变化：页面内容归属、数据交互、四角繁复花纹、新增装饰主题、游戏化元素。  
画布与安全区：优先 `1440×900`，同时验证 `1024×720`；关闭按钮和品牌头不得裁切。  
输出要求：三张同尺寸整页稿 + 一张横向三联对照稿。  
候选数量：两套受控方案；只变化品牌头布局（横向紧凑 / 左上竖向小组），其余材质不变。  
验收：并排看能立即认出同一套工作室系统，单独看仍能分辨来信、资料、故事。  
偏离回退：如果新木框或纸面生成失真，直接复用并局部裁切资料桌已批准素材，不重新生成整页材质。

## 9. 当前建议

优先出两套品牌头位置对照，但材质方案只保留一套，避免把确认问题扩大成多套完全不同的视觉方向：

- A（推荐）：左上横向 Logo + 完整名称，下方放页面主标题。三页最稳、最像统一产品系统。
- B：左上较大的 Logo，上下排列完整名称与页面标题。书卷气更强，但在沙发来信工具栏较密时会占空间。

若用户确认 A，下一步直接制作三页高保真三联稿，不进入代码实现。

## 11. 品牌位置第二轮调整

用户反馈来信页与故事角把完整品牌头放在左上后，标题区显得拥挤。第二轮保持资料桌不变，只调整另外两页：

- 来信页：Logo 与完整名称移到纸面底部，作为“工作室来信档案署名”；页面顶部只保留标题、搜索和关闭操作，截图为 `qa/unified-letters-brand-footer-1440x900.png`。
- 故事角：Logo 与完整名称移到左栏底部，作为“工作室故事集出版署名”；故事角标题和主题分类获得完整纵向节奏，截图为 `qa/unified-stories-brand-colophon-1440x900.png`。

两处品牌仍然使用同一 Logo、名称、字号和署名结构，因此保留系统一致性；位置根据内容语义不同，不再强求三页都固定在左上角。

资料桌随后同步为同一语言：保留居中的 `资料桌 / 工作室使用资料` 标题，移除左上品牌头，把 Logo 与完整名称放到底部“工作室资料署名栏”；右下用简短文字说明资料范围。截图为 `qa/unified-resources-brand-footer-1440x900.png`。

- 来信：工作室私人来信档案署名；
- 资料桌：工作室资料署名；
- 故事角：工作室故事集出版署名。

## 12. 正式实现与验收

正式实现已完成：三块面板共用资料桌胡桃木背板、暖象牙纸面、双细线圆弧内框、关闭按钮与基础色阶，并复用一个 `StudioSignature` 组件统一 Logo 和完整工作室名称。

2026-07-13 边缘复查：正式木框升级为 `resource-table-frame-clean-edge-v7.png`，以局部收缩 alpha 的方式清除深浅背景均可见的白色毛边和右上残点；沙发来信、资料桌、书架故事角统一为相同外部尺寸。木框不再整图拉伸，改用 `44 52 45 52` 九宫格切片和 28px 固定边宽，保证四边等宽，并让木框与独立纸面形成连续圆角。

转角衔接补正：木框 padding 区增加与内页一致的纸色底层，内页圆角收敛为 10px；四角不再露出等待室背景形成直角缺口。

最终转角方案：不再使用纸色底层遮缝，也不再使用旧木框九宫格。重新生成纯木质圆角框源，并制作 1404×828 的 `resource-table-rounded-ring-final-v9.png`：外圆角 48px、内圆角 20px、四边严格 28px；内页使用独立 20px 圆角，与木框内弧直接贴合。

厚度微调：正式引用更新为 v10，四边从 28px 收窄到 24px，内圆角与内页圆角同步为 24px，外圆角保持 48px。

色彩微调：正式引用更新为 v11，在不改变木纹、透明边缘和圆角的前提下，降低橘黄感、饱和度与明度，改为中深胡桃棕以贴合等待室整体木色。
