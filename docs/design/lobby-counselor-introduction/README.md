# L-014 咨询师介绍页设计定稿

状态：实现中
确认日期：2026-07-12  
执行工具：Codex（本分支唯一写入工具）  
分支：`feat/lobby-counselor-introduction-redesign`

## 设计目标

把现有偏密集、偏资料详情页的咨询师介绍，改成具有仪式感的“群心心理工作室介绍册”。用户从等待室右墙照片进入后，应当感觉自己被正式介绍给一位咨询师，同时能快速理解三位咨询师的专业差异并预约咨询。

可否证问题：新页面是否既增强了正式介绍的仪式感，又没有增加比较咨询师和预约咨询的阻力？若常见桌面比例下用户需要滚动才能看到预约按钮，或返回等待室不够明确，则设计不成立，必须降低装饰密度或压缩信息。

## 已确认视觉方向

- 采用第一轮效果图中的全屏编辑部人物专页结构。
- 最左侧增加半透明“返回等待室”窄边栏，形式参考第三轮效果图；边栏保留少量等待室空间感，但不占用主要阅读区域。
- 主页面是连续的暖纸张表面，不使用居中的厚重弹窗卡片。
- 左侧为咨询师人物主视觉，右侧为专业介绍；人物自然融入场景和纸张，不放入冷色或厚重方框。
- 使用用户提供的“群心心理工作室”Logo，不使用生成图中误造的英文、档案编号、竖排英文或页码。
- 纸张纹理、人物场景和必要装饰使用真实图片素材。CSS 只负责布局、响应式、排版、交互状态和轻量叠加，不用 CSS 渐变、噪点或几何绘制冒充核心美术素材。
- 整体颜色延续等待室：暖米白、胡桃木、克制灰绿色、少量暗红 Logo 与黄铜细节。

## 页面结构

### 1. 返回边栏

- 固定在页面最左侧，桌面宽度约 `64–76px`。
- 以半透明深木色覆盖在等待室局部背景上，包含清楚的返回箭头和“返回等待室”。
- 整块边栏可点击，支持键盘焦点；悬停只做轻微亮度变化，不做夸张位移。
- 窄高窗口下缩小为顶部返回条或更窄图标栏，不能遮挡人物和正文。

### 2. 人物主视觉

- 占内容区约 40%–44%，优先完整呈现头部、上半身和坐姿轮廓。
- 三位咨询师分别使用与现有正式会谈形象可辨认一致的介绍页专用素材。
- 人物背后是与等待室一致的暖木、书架、窗光氛围；画面右缘预留自然淡出区，便于与纸张正文衔接。
- 不直接复用设置页横幅作为最终主视觉，不修改正式会谈人物素材。

### 3. 顶部品牌与咨询师切换

- 左上使用“群心心理工作室”Logo。
- 右上展示程灵、周舟、林乐水三项切换，可带小头像；当前项以灰绿色短下划线和更高文字对比度标识。
- 切换不制造“角色卡”或角色图鉴感，不出现数值、稀有度、好感度或人格标签。

### 4. 专业介绍

信息顺序固定为：

1. 姓名；
2. 取向标题；
3. 她怎么看待咨询；
4. 她会怎样工作；
5. 主要咨询领域；
6. 预约状态与边界提示。

正文取自设置页现有 `counselorProfiles`，在介绍页内做精简与专业化，不修改设置页。避免“陪伴”“接住”等可能模糊专业关系的表达。

## 三位咨询师的精简内容

### 程灵

- 标题：人本精神分析取向心理咨询师
- 她怎么看待咨询：程灵重视真实、在场的咨询关系，也尊重来访者理解和表达自我的节奏。对她而言，咨询并非急于解释、修复或推动改变，而是为情绪体验与尚待澄清的内在经验，提供充分理解与深入探索的空间。
- 她会怎样工作：她从当下的感受与现实处境出发，关注内在需求、关系中的互动和内在冲突。她不会急于下结论，而会与你一起理解这些经验对你的意义。
- 主要咨询领域：亲密关系、内在冲突、自我探索、个人成长。

### 周舟

- 标题：焦点解决取向心理咨询师
- 她怎么看待咨询：面对复杂的现实困扰，周舟关注情绪、判断与现实条件如何交织，使人一时难以看清方向。对她而言，咨询并非用道理纠正感受或仓促给出答案，而是在理解处境的基础上，逐步厘清问题的结构、现实边界与可行方向。
- 她会怎样工作：她会从当下最需要处理的困扰出发，与你一起梳理实际发生的事情、你对此的理解与心中的担忧，并关注现实条件、已有资源和不同选择。她不会把咨询变成任务安排，而会在方向逐渐清晰后，协助你找到具体、适度且能够落实的行动。
- 主要咨询领域：压力调适、现实困扰、选择与决策、拖延与回避。

### 林乐水

- 标题：东方哲学取向心理咨询师
- 她怎么看待咨询：林乐水关注人在痛苦、迷茫与人生变化中，如何理解自己的处境，并重新思考生活的意义与方向。对她而言，咨询不是劝人放下，也不是提供某种人生答案，而是在尊重现实处境的基础上，面对生命中的选择、责任、失去与不确定，逐渐澄清自己真正珍视的价值。
- 她会怎样工作：她会从你正在经历的困惑出发，关注个人选择与关系、责任、文化和现实限制之间的联系。她会借助传统东方哲学对人生处境的理解，与你一起看清正在经历的事、真正看重的东西，以及接下来想怎样生活。
- 主要咨询领域：人生意义、生命转折、价值冲突、失落与哀伤。

## 预约与状态

- 未预约：主按钮显示“预约咨询”。
- 已预约当前咨询师：按钮显示“咨询工作中”并禁用。
- 预约失败：在按钮附近显示简洁失败说明，保留当前咨询师与已阅读内容，允许重试；组件只呈现上层传入的失败状态，不自行修改共享 store 或 IPC。
- 边界提示固定清楚表达：AI 心理咨询不能替代真人专业心理咨询、精神科诊疗、医学诊断或危机干预。

## 响应式与动效

- 16:9：人物与正文左右展开，预约按钮无需滚动即可见。
- 16:10：维持左右结构，适度收紧垂直间距。
- 窄高窗口：允许正文区域内部滚动；人物缩为半身且不遮挡切换和返回操作。
- 切换咨询师可使用轻微淡入；系统启用减少动画时取消过渡，不影响内容理解。
- 介绍页竖幅场景图统一以底部为裁切锚点：常见桌面比例下优先保留人物头部、完整坐姿、鞋履与椅子轮廓，只裁去少量顶部环境。
- 人物场景列同时受视口高度约束，宽度不超过 `60vh`；避免较宽、较矮的 100% 视口因 `cover` 裁切人物头顶。
- 宽屏下人物场景列最大宽度为 `640px`，正文最大阅读宽度随视口扩展至 `900–980px`；大视口会同步放大正文、标签、边界提示和预约按钮，避免 90% 浏览器缩放或高分辨率窗口下内容缩成页面中央的一小块。

## 素材计划

- 用户提供 Logo：作为品牌源素材复制到本专题素材目录，保留原图，不覆盖其他品牌素材。
- 新建 `assets/runtime/lobby/counselor-introductions/`：保存纸张背景、三位咨询师介绍页人物/场景素材及必要来源说明。
- 先生成一张可跨三位页面复用的无字暖纸纹背景；再为三位咨询师制作同画幅、同锚点、不同人物气质的介绍主视觉。
- 素材不得包含 UI 文字、按钮或切换标签，避免把界面文字烘焙进图片。

## 验收

- 三位咨询师差异清楚，资料与设置页含义一致。
- Logo 正确，页面无奇怪英文、编号和页码。
- 纸纹与人物主视觉为真实素材，细节达到效果图的温暖、精致程度。
- 预约、咨询工作中和可用的失败呈现正确。
- 16:9、16:10、窄高窗口可阅读、可切换、可返回、可预约。
- 专题测试、类型检查和构建通过。
