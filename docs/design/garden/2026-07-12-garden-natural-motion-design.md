# 花园自然轻动态设计

状态：待用户审阅  
任务：`L-017 花园` 第一阶段  
执行工具：`Codex`  
分支：`feat/garden-regulation-practice`

## 本阶段目标

先把湖畔花园的自然轻动态做好，让晴天与雨天看起来是同一处真实、安静的地点。正念呼吸练习留到动态效果验收后单独讨论，不在本阶段实现。

本阶段验证的问题是：局部低频运动能否让花园显得有生命力，同时不抢夺注意力、不引起晕动感，也不损伤现有插画质感。

若透明层无法与母图干净重合，或局部动画出现明显边缘、细节漂移、闪烁和性能抖动，则停止继续叠加效果，降级为静态母图加湖面微光或雨层。

## 已选制作路线

采用“静态母图 + 局部透明动态层”，不采用整张背景平移，也不采用多张 AI 微差帧循环。

- 静态母图锁定整体构图、树干、山线、湖岸、石径和花丛主体。
- 晴天只让近景叶冠、湖面反光与局部树荫轻微变化。
- 雨天只让独立雨丝、远景薄雾、近景叶冠和湖面雨点轻微变化。
- 所有动态由浏览器原生 CSS 驱动，不引入视频、Canvas 场景引擎、全局动画状态或第三方动画库。

这种路线能保持同一地点的稳定感，并让不同动态元素拥有各自节奏，不会出现整幅画面一起漂移的问题。

## 素材制作约定

### 用途与位置

素材只服务于 `OutdoorGarden` 全屏花园场景，覆盖在现有晴雨母图上。

### 当前视觉基线

继续使用：

- `lakeside-garden-sunny-v1.png`
- `lakeside-garden-rainy-v1.png`

两图均为 `1672 × 941`，构图一致。旧素材不删除、不覆盖。

### 锁定元素

- 画布比例与构图；
- 远山、湖岸、石径和树干位置；
- 当前温暖、偏写实的动漫自然插画风格；
- 晴雨两种天气仍能明确识别为同一处湖畔花园。

### 本轮允许变化

- 左上与右上近景叶冠的透明局部层；
- 晴天湖面反光与树荫纹理；
- 雨天雨丝、薄雾与湖面细小雨点；
- 为遮盖局部层位移边缘所需的少量自然补绘。

### 禁止变化

- 不重构花园布局，不添加人物、动物、建筑、文字或新功能入口；
- 不改变山线、湖岸和石径；
- 不生成独立构图的晴雨新图；
- 不使用横向扫描纹、强滤镜、雷电、闪光或大幅风吹效果。

### 输出要求

- 新素材放入 `assets/runtime/lobby/outdoor-garden/redesign/`；
- 局部层使用透明 PNG，并与母图保持相同画布和锚点；
- 文件按天气、元素和用途命名，不覆盖现有成品；
- 透明边缘在浅色天空、深色树冠、晴天母图和雨天母图上分别检查。

若直接抠取产生脏边或露出母图中的重复叶片，优先局部补绘或蒙版修复；不为追求动态而重新生成整幅背景。

## 动态设计

### 晴天

1. **近景叶冠**：左右两组分别以约 `7–11 秒`的不等周期做极小幅旋转和位移，方向不同，避免机械同步。树干保持不动。
2. **湖面反光**：使用低透明度遮罩缓慢横移，周期约 `10–16 秒`，只在湖面范围内出现。
3. **树荫呼吸感**：低透明度阴影遮罩以约 `12–18 秒`周期轻微改变位置和明暗，不模拟明显明灭。

### 雨天

1. **雨丝**：使用两层不同速度、不同密度的细雨，连续向下偏斜移动；保持低对比，不形成横纹。
2. **远景薄雾**：在远山和湖面上方缓慢横移，周期约 `16–24 秒`。
3. **叶冠**：幅度比晴天略小、节奏略慢，表现被雨水压住的重量感。
4. **湖面雨点**：只在湖区出现少量、低透明度的扩散纹，不覆盖前景花草。

### 共同节制规则

- 单个元素的视觉位移不超过其自身尺寸的约 `1%`；
- 不使用突然加速、弹性缓动和随机闪现；
- 天气切换采用短暂柔和交叉过渡，不同时展示两套完整动态层；
- UI 工具栏和文字层不随背景移动；
- `prefers-reduced-motion: reduce` 下停止叶冠、湖面、阴影、雨丝和薄雾动画，保留静态天气画面与全部操作能力。

## 页面结构

`OutdoorGarden` 保持为花园专题入口组件，本阶段在花园目录内拆出两个局部职责：

- `GardenSceneLayers`：根据天气渲染对应背景和装饰层，不持有大厅共享状态；
- 花园专属样式：定义层级、遮罩、动画、响应式裁切和减少动态效果规则。

天气仍由现有 `weather` 属性输入，切换仍通过现有 `onToggleWeather` 发出。专题内部不新增共享 store、路由、IPC 或会谈命令。

数据流保持为：大厅现有状态传入天气 → 花园场景选择母图和局部层 → CSS 执行动画。所有动画均为纯展示状态，不写入本地数据。

## 响应式与失败降级

- 背景和全画布透明层使用相同的 `cover` 逻辑与中心锚点，避免窗口变化后错位；
- 在 `16:9`、`16:10` 和常见窄高桌面窗口检查叶冠、湖面遮罩、标题和返回按钮；
- 素材加载失败时仍显示天气对应的背景色、返回按钮和天气切换，不阻塞退出；
- 低性能环境优先关闭树荫和湖面次级效果，保留静态背景；
- 不新增运行时网络请求，所有素材随 App 本地加载。

## 验收方式

### 视觉验收

- 静止观察时画面稳定，运动主要在余光中被察觉；
- 树干、远山、湖岸、石径和 UI 不发生漂移；
- 叶冠移动时无白边、黑边、色溢、重影或明显重复轮廓；
- 雨天无横纹、强闪烁或覆盖整屏的灰色滤镜；
- 晴雨切换后仍明确是同一地点。

### 功能与工程验收

- 返回等待室和天气切换保持可用；
- 减少动态效果设置生效；
- 花园相关组件测试通过；
- `npm run typecheck`、`npm test -- --run` 和 `npm run build` 通过；
- 不越过当前功能范围修改共享入口或咨询流程。

## 本阶段明确不做

- 正念呼吸引导及其时间、节奏和文案；
- 音乐、环境音和全局音频系统；
- “准备好，开始咨询”的共享接线；
- 新热点、共享状态、IPC、咨询 Prompt 或其他功能区素材。
