# 主咨询室设计说明

## 当前方向

主咨询室第一版采用三栏结构：左侧是本地会谈列表，中间是咨询式对话区域，右侧是当前咨询师、模型、咨询室主题和会谈状态。整体目标是让用户一打开就感觉进入了一个安静的咨询空间，而不是普通聊天窗口或管理后台。

## 视觉气质

- 主背景：米白、浅灰、低饱和蓝绿色。
- 层次：柔和阴影、克制半透明面板、清晰但不厚重的边框。
- 留白：页面保持呼吸感，避免信息密度过高。
- 控件：按钮和输入框以清晰可用为主，不做装饰性大按钮。
- 咨询师形象：第一阶段使用文字头像占位，暂不生成正式立绘。

## 当前页面组成

- 左侧：会谈列表、本地保存状态、新建会谈。
- 中央：咨询室主题、欢迎语、消息流占位、会谈输入框、结束会谈。
- 右侧：咨询师卡片、当前模型、当前咨询室主题、会谈状态、使用边界说明。
- 顶部：中文导航，包含咨询室、咨询师、记忆、设置。

## 审阅方式

- 日常 UI 审阅：打开 `http://localhost:5174/`。
- 桌面端效果审阅：运行 `npm run dev:electron` 打开 Electron 窗口。

## 本阶段不做

- 不接真实大模型调用。
- 不做正式咨询师立绘。
- 不做真实 SQLite 持久化。
- 不做会谈总结和自动记忆提取。
