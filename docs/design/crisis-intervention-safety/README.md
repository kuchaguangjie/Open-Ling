# 危机干预安全模块：资料评估与运行设计

## 结论

三本书都可作为专业背景资料，但不应整本放入模型上下文，也不能直接视为 2026 年临床规范。Ling 只吸收其中跨来源一致、适合文字 AI 的过程原则，并以当前官方指南校正旧内容。

运行上采用一份常驻但高度精简的《实时咨询安全原则》。它与《共同咨询价值观》采用相同写法：只保留会改变判断的方向性立场，不提供风险状态机、输出契约、固定问法或完整示例，把具体表达交还给当前咨询师。

安全原则不再单独规定共情步骤。它只要求安全与关系同时存在、具体回应当前处境，并保留充足心理支持；共情如何形成由咨询师核心角色和共同咨询价值观决定。

取消风险分级和“一旦触发就必须完成一个安全问题或动作”的隐性流程。只保留：没有真实处置价值就不问，确有必要时一次只澄清最关键的一项；危机回应不设字数上限，紧急医疗行动优先。

安全原则只提供共同底线，不接管咨询师的人格与语言。程灵、周舟和林乐水仍保持各自的核心性格、关系位置、措辞和节奏，不再从安全提示词中学习统一危机话术。

## 资料评价

### Crisis Intervention Handbook（第 4 版，Oxford University Press，2015）

综合型学术手册，覆盖危机评估、自杀危机、创伤、儿童青少年、脆弱群体、医疗场景和效果评估。对 Ling 最有价值的是 Roberts 七阶段框架：安全评估、建立关系、界定诱发事件、容纳情绪、寻找既往应对、形成行动方案、后续跟进。书中也强调阶段是指南而非僵硬顺序，危机工作应短程、目标明确，并在主动介入时保留当事人的问题所有权。

适合吸收：关系与安全并行、持续评估、关注当前诱发事件、调动既有优势、形成短期行动、后续确认。

不直接吸收：面向临床人员的量表解释、诊断和特定场景治疗技术；它们需要训练、监督及更完整资料。

### Suicide Prevention: A Practical Guide for the Practitioner（Springer，2018）

医疗系统取向的多作者实践参考书，作者来自精神医学、心理学、公共卫生、NIMH、Cleveland Clinic 等机构。覆盖神经生物学、精神障碍、儿童和特殊人群、急诊评估、医疗系统预防。对 Ling 最重要的是：区分长期风险因素与眼前预警信号；评估不能只靠单一分数；安全计划必须协作制定；减少危险物品可及性；“不自杀契约”无效且会制造虚假安全感；高风险期需要持续的支持性联系。

适合吸收：当前危险优先、协作式安全计划、环境安全、现实支持与跟进、风险信息不等于精确预测。

不直接吸收：药物、住院指征、急诊处置和针对特定疾病的治疗建议；AI 不具备临床处置角色。

### Crisis Intervention Strategies（第 8 版，Cengage，2017）

危机干预课程教材，实践和技能训练色彩最强。其混合任务模型比固定步骤更适合对话系统：建立联系、从当事人视角界定危机、提供支持、探索替代方案、恢复控制、形成承诺、跟进；情绪、行为、认知和现实处境需要持续观察。网络危机咨询章节强调文字媒介一次聚焦一个中心问题、一次问一个问题，并预先准备转介和紧急支持。

适合吸收：非线性任务模型、共情先于盘问、一次一个问题、短期恢复行动能力、持续复评。

明确排除：书中仍保留的“不伤害契约/存活契约”示范。该做法与书内其他保留意见、另外两本书及当前指南均冲突，不能进入 Ling。

## 写入提示词的规则

- 安全默认保持背景，不凭死亡、自伤或绝望关键词单独触发；同时不能忽略明确而当前的死亡或伤害意愿。
- 共情、判断和行动可以并行，不执行固定的“共情—询问—转介”流程。
- 回应这次危机的具体处境或诱发事件，避免“听起来”等机械共情开头。
- 不设必问题。确有必要时，只问一个会改变近期处置的当前信息；不复述方法，不索取实施细节，不把危险行为呈现为选项。
- 已知有伤害念头不自动等于询问是否受伤；问题来自本轮真实的信息缺口。
- 风险越急，现实行动越清楚、主动，但不压缩掉必要的关系支持。
- 保留可行选择和当事人的主动性，同时在眼前危险时明确推动现实介入。
- 短暂稳定只为恢复行动能力，不能证明危险解除。
- 安全计划必须协作、具体、可执行，并包括现实支持与环境安全；不使用“不伤害保证”。
- 分数、保护因素、短暂平静和口头保证都不能单独确认安全。
- 行动后确认真实发生了什么，并在现实帮助连接期间继续提供心理支持。
- 现实危险得到基本澄清或控制后，及时回到咨询内容，不持续停留在风险评估。

## 边界

该模块是面向 AI 回复的安全行为约束，不是临床培训课程、诊断工具或自动风险预测器。书中的原文、表格和量表不复制进产品；本仓库只保存经过归纳的规则。紧急号码和法律要求需要按地区单独维护并定期核验。
