# 全应用逻辑审核与使用说明（2026-09-07）

## 目标与验收

沿用 `feat/api-key-settings-fix`，保留本分支已经完成的 API Key 修复。重点检查启动恢复、模型配置、基础设置、预约、新开/结束/继续会谈、前台引导及说明。验收以可复现问题的回归测试、全量测试、类型检查、构建和浏览器交互为依据，不把测试通过解释为所有设备与网络下绝无故障。

## 本轮修复

| 问题与触发 | 修复后的行为 |
| --- | --- |
| 修改模型分工后放弃设置，分工草稿仍留在内存 | 补齐已保存分工快照；放弃修改会完整恢复 |
| 切换语言、启停扩展咨询师或修改默认咨询师，顺带保存其他页面草稿 | 设置写入只合并本次明确保存的字段，其余采用已保存值 |
| 多个设置保存各自读到旧配置，后完成者覆盖先完成者 | 读取、字段合并与保存按顺序执行；失败不会阻塞后续重试 |
| 保存个人资料、外观、连续性或语音期间继续编辑，后续编辑被误标已保存或覆盖 | 固定提交时的快照；较新的编辑保留为未保存 |
| 恢复推荐设置把本机/自定义服务换成 DeepSeek 模型，并清理无关草稿状态 | 保留对应服务的模型选择；只恢复有关设置，保留无关草稿 |
| 正式会谈创建、发送或预约准备读取到未保存的 API 草稿 | 正式流程读取已保存配置；设置页测试仍可使用当前草稿 |
| 用户离开预约或新开流程，历史读取稍后返回又创建会谈 | 在创建前核对操作是否仍有效；取消或卸载后的准备不再继续 |
| 旧开场取消/启动、结束状态检查、继续会谈或来信读取结果影响当前页面 | 核对发起操作时的流程对象；同一会谈重新打开也不会接收旧流程的导航结果 |
| 启动时设置读取异常被当成“没有设置”继续 | 展示读取失败与重试，保留原恢复指针，避免使用默认配置继续 |

前一轮 API Key 修复仍保留：测试和读取模型优先使用本次输入，留空才用已保存密钥；测试不保存；成功保存后移除明文；修改配置使旧测试结果失效。

## 已审查的现有保护

- 新开会谈：主进程按咨询师串行处理，原子替换未完成会谈；创建失败时不先结束旧会谈。
- 流式会谈：发送、停止、重试、切换和结束的互斥；过期请求与后台整理周期的隔离。
- 历史与恢复：数据库状态读回、未完成开场恢复、结束状态不确定时重新读取、只允许继续最近结束且无其他未完成的会谈。
- 数据：备份/恢复、导出、凭据存储、密码恢复及 IPC 边界，沿用现有测试覆盖；未改备份格式和数据库结构。

## 面向用户的说明

- 三位咨询师各增加 5 条简短前台介绍，覆盖第一次表达、暂停/结束、咨询连续性、备份和模型接入；中英文同步。
- “随便聊聊”首次说明明确：这是预写导览，不调用 AI，不生成咨询记录。正式会谈的数据流向单独说明。
- 使用帮助增加“第一次使用，从哪里开始”“模型和 API Key 是什么”，校正新开/继续条件、未发送草稿不跨重启保存、语言与其他设置的保存方式、本机/网络地址及备份用途。
- 说明介绍基本使用，不围绕内部修复细节组织内容。

## 验证与限制

- 新增 16 项异常与状态边界回归，覆盖设置写入、会谈流程、预约取消和启动恢复。
- 全量测试通过：123 个测试文件、829 项测试；TypeScript 类型检查、本地化校验和生产构建通过。
- 浏览器检查前台介绍、逐句推进与退出，以及使用帮助目录和新增内容。
- 使用虚构配置、内存桥接与隔离临时数据库；未读取真实密钥，未触碰真实会谈数据。
- 本轮没有做真实服务商付费请求、麦克风硬件测试、系统断电/磁盘损坏测试，也未逐个平台安装发行包。相关平台与外部服务仍需要发布前实机验收。
