# Ling 项目身份规范

本文档统一 Ling 在产品、开源社区和对外合作中的身份表达，避免把法律主体、项目品牌和 App 内角色混为一体。

## 身份层级

1. **上海啸群教育科技有限公司**：官方发行、版权、品牌权利、隐私与对外合作中的正式主体。
2. **Ling**：唯一对外产品与开源项目品牌。
3. **Ling-Team**：Ling 官方 GitHub 维护账号，不是独立法律主体。
4. **Ling Desktop**：Ling 的官方桌面软件产品。
5. **群心心理工作室**：App 内的 AI 咨询师团队设定，不是公司、真人心理咨询机构或责任主体。
6. **程灵、周舟、林乐水**：Ling 的官方 AI 咨询角色。

## 不同场景的口径

| 场景 | 主要呈现 | 正式主体处理 |
| --- | --- | --- |
| App 启动与欢迎页 | Ling 品牌、AI 身份、本地优先与服务边界 | 不在品牌主视觉中展开公司信息 |
| About | `Ling`、版本号、`维护团队 @Ling-Team`、联系邮箱、项目地址、`© 2026 Ling-Team` | 使用精简居中布局，不展示公司名称，不重复添加字段标签 |
| 知情同意 | AI 身份、服务局限、数据流向、危机边界和用户选择 | 在发布与联系信息中明确公司主体 |
| 使用说明 | Ling 品牌、App 内世界观和官方仓库入口 | 不必在介绍首段反复强调公司 |
| GitHub README | Ling、`@Ling-Team`、技术定位、开源范围和社区入口 | 明确官方发行和版权主体 |
| LICENSE | Apache-2.0 License | 版权人只写上海啸群教育科技有限公司 |
| 官网 Footer | Ling 项目简介与官方 GitHub 入口 | 列出公司全称与版权信息 |
| 企业与机构合作 | Ling 的专业化能力与服务 | 由公司作为签约和服务主体 |

## 使用限制

- `Ling-Team` 作为 GitHub 账号、开源维护身份和 App 展示层版权署名，不替代公司出现在 LICENSE、法律文件或需要明确服务提供者的位置。
- `群心心理工作室` 不用作版权人、发行人或真人专业服务机构。
- `openling` 仅作为联系邮箱中的字符串，不作为独立项目品牌使用。
- 官方 GitHub 地址统一为 `https://github.com/Ling-Team/Open-Ling`。
