# Ling 公开发布素材权利记录

本文档是公开仓库的发布判断，不替代公司内部合同、订单、原始文件或生成记录。内部证明不得上传到公开仓库；公开仓库只保留必要的来源、许可、修改说明和权利边界。

## 公司内部需要留存的证明

发布负责人只需在公司受控存储中保留下列内容，无需把合同或原始隐私材料放进 Git：

1. 公司主体信息，以及代表公司批准首次开源发布的记录。
2. Ling、群心心理工作室、应用图标和各版 Logo 的原始文件、首次使用时间、设计者或提供者，以及委托/转让/授权记录（如有）。
3. 程灵、周舟、林乐水的名称和官方形象母版，角色设定形成时间，参与制作人员，以及委托/转让/授权记录（如有）。
4. 用户或项目成员提供给图像生成/编辑工具的每一类参考素材，其来源和允许用于派生制作的依据。
5. AI 辅助生成或编辑素材的工具、日期、输入参考、关键生成记录、人工修改记录和最终采用文件。无需公开完整提示词，但应足以证明生产链路。
6. 外部设计、采购字体、摄影、录音或模型一旦新增，保留订单、发票、合同、许可版本与下载日期。

如果某项官方视觉素材无法回答“是谁提供、依据什么权利、何时成为最终版”，在补齐记录前不应进入公开源码或公开安装包。

## 已知但可接受的透明度限制

- X-ASR 上游模型卡授权模型权重使用 Apache-2.0，但尚未提供可逐项独立审计的完整训练数据清单。公开说明必须保留这一限制，不能改写成“训练数据已经全部审计”。
- AI 辅助生成不自动证明素材具有排他的著作权。Ling 对官方品牌和角色的使用边界主要通过公司生产记录、商标/反混淆政策和具体素材许可共同维护。
- 仓库中保留权利的官方素材可供构建官方源码，不等于第三方可以用相同 Logo、角色形象或品牌装潢发布修改版。

## 每次发布的复核动作

1. 对照 `assets/ASSET_SOURCES.md` 检查新增或替换素材。
2. 核对第三方来源页面、许可版本、署名和修改说明仍然准确。
3. 确认公司内部权属记录可以对应到本次实际发布文件。
4. 运行 `npm run public-boundary:verify`，再从无 Git 历史的导出目录进行一次人工抽查。
5. 发现来源不明或权利冲突时，先从公开版移除或替换，不以仓库根目录 Apache-2.0 License 覆盖问题。
