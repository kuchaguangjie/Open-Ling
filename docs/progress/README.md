## 主要风险

- API Key 已使用系统安全存储加密保存；正式安装包中的 macOS/Windows 迁移与系统凭据兼容仍需验证。
- 本地密码锁不是数据库文件级加密，需要避免对用户暗示“资料已加密”。
- `better-sqlite3` 在 Node、macOS Electron 与 Windows Electron 间存在 ABI 切换成本；当前打包资源检查已覆盖，正式安装升级仍需持续验证。
- 英文心理专业内容已工程化并完成语言一致性门禁，但仍需目标地区的专业、法律合规和危机资源审阅。
- 心理支持产品的模型输出质量与安全边界仍需要持续人工复验。
