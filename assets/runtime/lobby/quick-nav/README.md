# 等待室快捷导航图标

本目录保存等待室底部快捷导航的生产素材。三个图标均使用内置 Image Gen 生成平面绿幕源图，再通过本地色键、柔化边缘和去绿色溢色处理为透明 PNG。

- `quick-nav-letters-transparent-v1.png`：咨询师来信，暖象牙色信封与暗酒红火漆。
- `quick-nav-appointment-transparent-v1.png`：预约咨询，两张浅色花纹布艺单人沙发与深砖红圆形波斯地毯。
- `quick-nav-settings-transparent-v1.png`：系统设置，黄铜齿轮与深胡桃木内芯。
- `quick-nav-walnut-surface-v1.png`：导航底座与三个按钮共用的暖胡桃木表面纹理。

生产约束：图标无文字、无按钮底板、无外部投影；由前端统一控制显示尺寸和交互状态。透明边缘已在浅色与深色背景上检查。木纹素材只提供表面纹理，边框、倒角和交互状态均由前端实现。
