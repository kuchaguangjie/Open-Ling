## 图形含义

图形保留旧“群心心理”标志中的三人共同承托关系，最终采用不带圆环、无文字的三人舟版本。主体兼具舟、承托手势与单笔墨迹的多重意象，强调同行、容纳和开放，不使用医疗、诊断或封闭保护符号。

## 透明处理

原图为浅米色背景上的单色酒红图形。通用抠图模型会丢失舟身或在深色背景上残留浅色描边，因此最终资产采用颜色反混合计算半透明边缘，并保留原始枯笔纹理。透明结果已在浅色、深色、暖纸色、胡桃木色及当前等待室背景上检查。

## 使用约束

- 后续需要 Logo 的生成图或合成图，优先使用透明 PNG 作为锁定参考或独立叠加层。
- 不在图标旁自动补回“群心心理”或 `Ling` 文字。
- 不擅自增加圆环、波浪、爱心、脑部、医疗十字或对话气泡。
- 需要改变颜色、比例或笔触时，从本目录母版派生新版本，不覆盖 `v1`。
