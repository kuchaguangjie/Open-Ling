- `hd-frames/`：五张 `1536×1536` 高清像素帧，包括睁眼、半闭眼、闭眼、小开口和中开口；正式播放只使用稳定的睁眼与闭眼帧。
- 所有帧使用同一人物母图与 alpha；头发、衣服、记录本、手、胸牌、鼻子、脸颊和下颌不参与口型动画。

- 口型帧只修改嘴唇局部，嘴巴区域外 RGB 差异为 0。
- 胸牌使用群心原始 Logo 的较大居中方案，并在五张帧中保持完全一致。
