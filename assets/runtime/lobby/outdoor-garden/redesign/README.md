## 制作记录

使用内置 Image Gen，以现有晴雨母图为锁定参考：

1. 提取左右近景叶冠到纯品红背景；
2. 使用本地 chroma-key 工具生成软边 Alpha 并去除品红溢色；
3. 生成移除可动叶冠的晴雨干净底板；
4. 以左叶冠 Alpha 扩展 35 像素并羽化 14 像素，只把该局部补绘回原始母图，离线合成为无缝动态底图；
5. 右侧树木保持原母图完整像素，避免树干与树冠分层后断裂；
6. 在黑、白、暖棕和对应花园底板上检查透明边缘，并逐帧检查晴雨动画首尾位置。

接入文件未发现品红残留、明显黑白光边或背景碎屑。左上叶冠只绘制一次，整体围绕靠近枝干的锚点做 2–5 像素低频摆动并同步改变明暗，避免多个同源叶簇柔边相互覆盖产生重影；底图补绘区负责承接露出的叶后空间。湖面、湖岸和周边树木保持静止，晴天使用限制在湖面轮廓内的双层细碎横向反光纹理缓慢明灭，不再使用独立闪光点；树荫、雨丝和薄雾由 CSS 生成。
