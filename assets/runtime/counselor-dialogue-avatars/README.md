# 咨询师对话头像素材

本目录用于归档咨询师在消息气泡圆形头像中使用的最终头像。

## 当前约定

- 程灵沿用主线原版头像；周舟、林乐水使用新的 Q 版角色设定头像。
- 头像为透明 PNG，并将用户确认的圆形取景参数烘焙进周舟、林乐水素材。
- 主线只保留当前接入的最终透明 PNG，便于放入对话圆形框。
- `dialogue-avatar-preview.html` 是独立静态测试页，可直接在浏览器打开，预览三位咨询师头像在消息气泡中的切换效果。

## 当前接入

- `chengling/chengling-dialogue-avatar-pixel-v8-user-frame-transparent.png`：程灵主线原版头像，保持不变。
- `zhouzhou/user-selected/zhouzhou-dialogue-avatar-q-style-v1-cropped-transparent.png`：周舟新聊天头像，采用确认选区 `x -1.2%, y 19.0%, scale 1.33`。
- `linleshui/user-selected/linleshui-dialogue-avatar-q-style-v3-cropped-transparent.png`：林乐水新聊天头像，采用确认选区 `x -0.3%, y 15.6%, scale 1.25`。
