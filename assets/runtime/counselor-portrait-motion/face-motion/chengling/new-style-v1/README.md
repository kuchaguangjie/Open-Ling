# 程灵新版咨询立绘脸部动态 v1

本目录保存与新版 `1024 × 1536` 三态立绘逐姿势配准的透明覆盖层：

- `default/`：默认持杯态闭眼层；
- `listening/`：托腮倾听态闭眼层；
- `responding/`：回应态闭眼、轻启口与自然张口层。

制作方式：以正式运行时立绘为母图，仅局部编辑眼睑或嘴唇；通过 SIFT/RANSAC 将编辑源重新配准到母图，再抽取完整画布上的小范围羽化贴片。覆盖层不包含头发、首饰、衣服、杯子、手或椅子的改动。

运行规则：三态均以 6–8 秒随机间隔眨眼，闭眼约 130–150ms；只有 `streaming` 回应态以 `轻启 → 张口 → 轻启 → 中性` 的节奏循环口型。系统开启“减少动态效果”时保持中性帧。
