# 咨询师立绘与动态效果素材

本目录用于归档咨询室右侧咨询师立绘、状态变体、分层源文件和动态效果审阅图。

## 分层约定

- 背景层：继续使用咨询室主题自己的无人空间背景，不在本目录重复归档正式背景。
- 人物 + 椅子层：第一阶段保持为同一张透明 PNG，避免椅子和身体在轻动画中错位。
- 状态卡层：由前端 CSS 和组件渲染，不生成到人物图片内。

## 状态命名

- `idle`：安静在场。
- `listening`：用户聚焦输入时，轻微倾听感。
- `thinking`：连接模型或整理内容时，更慢、更静。
- `empathizing`：后续用于共情靠近状态，第一阶段预留。
- `responding`：流式回应中，轻微浮动更明显。
- `error-soft`：模型连接异常时的柔和失败状态，不做警报式动效。

## 当前阶段

第一阶段先接入 CSS 轻量动态与状态映射，暂不新增正式状态立绘。后续生成的新素材应放入本目录下的咨询师子目录，例如：

```text

```

旧素材继续保留在 `assets/runtime/counseling-room/` 和 `assets/runtime/home-ui/`，未经确认不删除。
