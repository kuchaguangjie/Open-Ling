# 程灵咨询室背景

本目录归档程灵当前咨询室横向大背景。

## 当前接入

- `chengling-warm-fireplace-study-background-v1.png`：当前程灵主会话界面的横向背景，已作为整张咨询室背景接入。

## 设计说明

- 背景策略与周舟、林乐水一致：使用完整横向主会话背景，不再叠加独立右侧背景贴片。
- 画面保留暖色欧式书房气息：中央直线型大壁炉、一幅暖色风景画、右侧书架和落地灯。
- 左侧保留较低信息量的墙纸与植物影，便于叠加会谈列表；中间壁炉区域保持柔和对比，便于叠加对话面板。
- 右侧不放桌子、躺椅或人物头像摆件，避免与程灵立绘自带椅子和前景关系冲突。
