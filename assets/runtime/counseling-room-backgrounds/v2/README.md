# 咨询室背景 v2

本目录保存 C-005 咨询背景任务的新一轮候选与定稿素材，不覆盖项目当前已接入的旧背景。

## 目录约定

- `<counselor>/opening/`：用户进入咨询室后的开场对白、正式咨询结束后的收尾对白使用。背景保留两把咨询椅和茶几，前景人物使用不带椅子的半身立绘。
- `<counselor>/session/`：正式咨询消息流和输入框出现后使用。背景删除右侧咨询师椅，保留左侧椅子和茶几，右侧叠加自带椅子的咨询师立绘。
- `<counselor>/old/opening/`：开场/收尾全景的历史候选。
- `<counselor>/old/session/`：正式咨询单椅背景的历史候选。
- 后续代码接入只引用 `opening/` 与 `session/` 中的语义化文件，不直接引用 `old/`。
